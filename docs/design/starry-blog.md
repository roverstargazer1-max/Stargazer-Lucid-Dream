## 1. 设计目的与边界

这是作者自己的个人项目，首先服务于作者的表达和趣味。希望愿意了解作者、同样认为有意思的人，通过探索找到共鸣并记住这个个人世界；不以普遍接受度或留存率裁决设计。

文章成为星星，文章之间的关联可以被观察和探索。星座只预留整体名称的展示位置，不承担写作主题、栏目或要求作者围绕它创作的职责。

全站统一在同一片星空中。归档与友链以场景物件或信号呈现；旧地址保留，打开对应的新状态。2026-09-30 确认首版不新建作者介绍或首页介绍入口，旧关于地址仍承接已有内容。重做呈现方式不要求删除已有文章和素材。

## 2. 空间与视觉

## 3. 双模式与空间生长

| 规则 | 关联模式 | 时间模式 |
| --- | --- | --- |
| 默认状态 | 首页默认模式 | 可切换的另一模式 |
| 组织原则 | 已确认的文章关系 | 发表时间由早到晚向前延伸 |
| 新文章 | 尽量靠近已确认关联，同时保留留白 | 接在时间序列更远处 |
| 已有文章位置 | 保持稳定，不因新增文章全局重排 | 按时间顺序呈现；补发旧日期文章的细节交由工程规则处理 |

| 命名要求 | 不强制归入命名星座 | 不要求围绕主题写作 |

有选中文章时切换模式，在新布局中继续聚焦同一篇文章。两种布局必须识别同一篇内容，不能依赖当前数组序号推断身份。

镜头真正向目标附近推进：近处星星从身旁移过，远处星星逐渐靠近，屋顶退出视野。停在仍能看清目标与附近少量文章的位置。

### 已确认的状态变化

| 当前情况 | 操作或事件 | 结果 |
| --- | --- | --- |
| 自由探索或选中了另一颗星 | 首次选择文章星 | 选中、显示引言并开始推进；不打开正文 |
| 正在自动推进 | 对同一目标重复点击 | 不打开正文，不把重复点击排队为稍后打开 |
| 已到位且仍选中该星 | 再次点击该星 | 进入正文阅读层，无须快速双击 |
| 选中一篇文章 | 观察关联 | 显露关联星与淡线，可以继续探索关联文章 |
| 正文展开 | 到达正文末尾 | 满足显露作者确认关联理由的条件 |
| 短文展开后即完整可见 | 正文完成布局 | 同样满足条件，无停留时长要求 |
| 正文阅读层关闭 | 返回星空 | 恢复进入前的视角和选中星 |
| 已选中文章 | 切换模式 | 在目标布局继续聚焦同一篇文章 |

阅读判定只是交互触发信号，不判断访客是否认真理解文字。阅读前可以沿关系导航，阅读后增加的是解释，而非正文访问权限。

桌面正文层边缘留少量星空，手机正文占满可用区域。通过旧文章链接也能直接进入阅读层，无需先在星空中寻找或解锁。

移动中更换目标、手动中断、内容层手势隔离与停靠历史等收尾规则见第 9 节。

## 5. 星空中的归档、关于与友链

以下映射承接早期 Q27；关于一项已按 2026-09-30 主题化整体确认调整。

| 内容 | 场景载体 | 行为 |
| --- | --- | --- |
| 归档 | 屋顶上的星历盘 | 选择年份或月份，进入时间模式，移动到对应时期的文章附近 |
| 旧关于内容 | 原地址直达的轻量兼容内容层 | 承接原内容及歌单，首版不增加新的首页介绍入口；书桌物件跳转新介绍暂缓 |
| 友链 | 星空中一组遥远的信号 | 触发后显露朋友名字、简述与网站入口；主动选择后前往对方网站 |

没有常驻的“归档／关于／友链”文字菜单。功能入口通过形状、微光或小幅运动留下细微异常，靠近或触碰时给出反馈；纯趣味彩蛋可以完全隐蔽。

归档入口随当前窗边场景组织，深处探索时可返回入口寻找。首版不新增关于物件；友链信号的具体位置属于场景排布，不要求每个探索视野都显示全部朋友。

功能内容在同一个世界中展开，不跳回旧主题布局；朋友的网站仍是明确的外链目的地。趣味彩蛋只做少量小交互，具体形状和反馈可在视觉制作时提出样例，不自动扩展为隐藏地图或任务系统。

## 6. 内容维护与 AI 辅助

### 已确认的作者流程

1. 在本地文件中写文章。
2. 引言可手填，未填写时自动提取正文开头。
3. 文章位置和基础外观自动生成。有精力时补关联，没精力时仍能正常发表，以后再补。
4. 关联和可选星座名称保存在仓库配置中。
5. 按需让 AI 阅读文章、提出少量关联候选和理由。
6. 作者接受、修改或舍弃候选，只有采用的结果进入公开星图。

AI 建议不是访客端实时功能，也不要求站内后台。未处理候选不自动公开、不阻止发表。首版不以接入特定 AI 服务或搭建自动调用系统作为前提。

### 早期数据约束与当前格式

| 对象 | 所需信息或约束 |
| --- | --- |
| 文章 | 跨布局可识别的身份、原地址、标题、日期、正文、可选引言 |
| 文章关联 | 两篇文章的引用、作者采用的理由；候选与采用结果需可区分 |
| 关联布局 | 文章身份到稳定位置的分配，新增不重排已有文章 |
| 时间布局 | 日期顺序与文章身份，同日期排序可重复 |
| 星座显示 | 可选名称与对应星组，不生成写作主题要求 |
| 功能物件 | 星历盘、友链信号的配置与内容入口；旧关于内容另做地址兼容承接 |

当前格式已实现：文章 Front-matter 保存 `starry_id`、原链接和描述，`related` 按文件名引用文章、理由选填并自动双向；稳定位置保存在 `source/_data/starry-layout.json`。`npm run preview:starfield` 自动准备并生成，生产构建只读取已保存数据。可选星等、孤立状态及字段维护以 [写作指南](../operations/starfield-blog.md)为准。

## 9. 范围内默认规则（2026-09-30 已整体复核）

用户已确认整体方案及收尾规则暂无调整。本节作为首版默认值，R5 的新彩蛋提案移出首版，R6 与旧关于承接按本次确认更新。此确认仅指产品和实施要求，不代表代码、真机或部署已经验收。

### R1. 当次状态与返回

- 没选中文章时切换模式，进入目标模式的默认起点；有选中文章时遵循 Q21。
- 两模式共享当次阅读标记，切换不清除；刷新或重新访问不恢复历史探索。
- 每次完成自动停靠记录返回点；手动巡视不逐帧记录。切换模式后，以目标布局当前落点建立新的停靠起点，避免直接使用另一布局的坐标返回。
- 关闭由旧地址直接打开的文章时，回到关联模式的对应文章附近；没有前置历史也能回屋顶。
- 浏览器前进后退与当前内容层地址一致，避免网址和画面所指文章不同。

### R2. 时间模式与理由

- 时间相邻不创建语义关联，时间模式默认不展开语义关联线。
- 已满足阅读条件的文章仍能在信息区查看作者采用的关联理由；只有日期相邻的文章不生成虚构理由。
- 阅读当前文章即可显露其已采用的关联理由，不要求两端都读过；无理由时不填充占位文案。

### R3. 中断与内容层

- 自动推进时选择另一颗星可更新目标，手动转向或前后移动可中断推进。
- 中断后再次点星先完成选中与靠近，避免误作直接打开正文的第二次点击。
- 点击空白取消选中，拖动结束不视作空白点击；镜头留在原处，收起引言和选择提示。
- 阅读、手记或功能内容层展开时，其滚动和触摸不驱动背后的镜头。

### R4. 展示数据

- 自动引言使用简短纯文本，排除标题、播放器和图片语法，支持手填覆盖。
- 星座名称未填就省略；配置只声明名称和对应星组，不推导写作主题，也不因命名重新布局。
- 关系引用失效或缺少可选信息时，给作者可定位的提示；有效文章仍有独立入口。
- 星历盘只提供有文章的年月，选定后定位该时期的起始文章，避免跳到空区。

### R5. 彩蛋反馈

- 桌面靠近或悬停出现轻反馈，点击展开功能；手机首次触碰提示，再次点按展开。
- 沿用原型已有的小交互，不追加原稿中尚未制作的两项新彩蛋。空白引力扭曲及新星尘彩蛋的早期提案暂缓；既有入口引导效果保留，不增加隐藏地图或任务系统。
- 友链外部网站在新标签页打开，保留当前星空；只有主动选择网站入口才前往对方网站。

### R6. 音乐与素材

- 保留原始文章、图片与音乐配置文件；正文中已有的音乐支持主动播放。
- 旧关于／归档页单独附带的歌单或单曲不自动成为新版全站背景音乐；全站自动播放不作为首版要求。
- 是否把音乐进一步做成场景物件留待以后选择，不增加到当前首版。
- 旧关于地址仍承接现有内容及歌单，但首版不把它制作成新的手记入口或作者介绍；书桌物件跳转新介绍作为后续候选。
