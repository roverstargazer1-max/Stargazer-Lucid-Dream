# 补充图形裁片

这些 PNG 从作者提供的 `../补充图形.png` 直接裁切，保留原像素和透明度，不重绘、描边或矢量化。

`crops.json` 记录原图来源和每个裁片的 `[left, top, right, bottom]` 坐标，原点为左上角，右边界与下边界不包含在裁片内。年份数字及 YE 单独叠放，年份箭头裁片本身不含文字。

主题构建按原样发布裁片；数字和其余技术字母使用现成的透明 PNG 字形。

`call-word.png` 和 `call-underline.png` 将原 CALL 裁片按同一横坐标分成上下两段，以独立调整横杠的垂直位置；两段都直接取自原图，不修改其像素。
