# V19 原型下一步优化计划

日期：2026-09-14。

状态：本轮计划已完成（2026-09-14 授权执行，2026-09-15 完成本地 V20 原型、对照、可用环境验收和交付记录）。逐项完成状态、未获得的真机/性能结论及其限制见 [执行与验收记录](optimization-v20-acceptance.md)。以下参数保留为原试作起点，最终采用值以验收记录为准。

依据：[首版设计](../../docs/design/starry-blog.md)、[当前原型说明](../../themes/hexo-theme-kira/prototypes/starfield/README.md)、[V19 演进记录](../../themes/hexo-theme-kira/prototypes/starfield/MOTION-STUDY-19.md)，以及本次会话上一轮的实际页面评审。主设计中的 R1–R6 继续保持待整体复核状态。

本计划以当前 C 方案、厚涂星空、窗边入口为基线。优化目标是让内容更容易发现、常用动作更明确、文字阅读更舒适，并保留安静探索与个人表达。

## 1. 已有依据与需要验证的判断

| 项目 | 已有依据 | 本计划如何处理 |
| --- | --- | --- |
| 紧凑屏幕简介 | 上一轮在 320×568 CSS px 视口中，《给未完成的事留一扇窗》末行仅剩“窗”；简介可用高度约 239px、内容约 318px，“进入阅读”在内部滚动区下方，默认不可见 | 首先修复，不依赖美术取舍 |
| 交互热区 | 简介关闭约 14×12px；手机顶部部分图标约 23×30px；文章星已有约 44×44px 热区 | 统一常用控制的点击尺度，保留星光的小尺寸 |
| 辅助文字 | 手机底部约 8px，部分日期、理由约 9px，导航约 10px；部分文字有叠加透明度 | 明确功能文字的字号和对比度层级 |
| 正文排版 | 正文 16px；桌面约 2.15 倍行高，手机约 2 倍；桌面实际文字宽度约 616px | 保留可读的基础，微调顶部与段落组之间的间距 |
| 核心流程 | 上一轮已实际体验点星、正文、返回、手记、广角，以及切换模式继续聚焦同文 | 将这些行为纳入本轮回归检查 |
| 文章星辨识度 | 部分视角下月亮和云层更抢眼，文章星位于云纹上时不易辨认 | 用固定视角对照验证；不据此宣称访客必然找不到文章 |
| 窗口发现率 | 手机无悬停反馈，微光可能被当作装饰 | 保留现状作为对照，观察发现过程后决定是否增强 |
| 动效负担 | 当前入场约 2.5s、简介约 2.8s、归窗约 2.6s；连续重复的体验尚需专项比较 | 保留首次仪式感，试验同次访问中的重复简介简化 |
| 配色与字体一致性 | 色彩主方向已协调；云层层次、不同系统的字体呈现属于视觉判断或待验证项 | 放在核心易用性改进之后做有针对性的比较 |

这些尺寸来自上一轮本地浏览器评审，不是本计划修改后的验收结果，也不代表手机真机结果。

## 2. 工作顺序与交付

| 顺序 | 工作包 | 主要产物 | 进入下一步的依据 |
| --- | --- | --- | --- |
| 0 | 保存可复现基线 | 当前文件版本、预览设置、代表性视角与测量记录 | 能重新打开同一画面比较 |
| 1 | 简介与常用操作 | 固定主要动作的简介、合适的热区、小屏换行 | 紧凑屏幕可以直接找到并完成主要操作 |
| 2 | 字体、间距与阅读 | 统一字号表、局部间距、图标与文案 | 文字清楚，长短内容均可阅读 |
| 3 | 文章与探索层级 | 星光对照、局部背景处理、停靠与方向提示 | 内容可辨，稀疏与远近感仍然成立 |
| 4 | 动效与模式表达 | 重复简介轻呈现、按钮状态衔接、短暂时间标记试验 | 连续探索自然，状态没有歧义 |
| 5 | 美术收尾与综合验收 | 配色对照、小尺寸字标、验收记录 | 实际问题已解决，待验证项有清楚记录 |

每个工作包完成后保存可独立比较的结果。发现明确的布局或状态问题时先解决；视觉偏好只在该项存在可见收益时采用新方案。

## 3. 工作包 0：可复现的比较基线

1. 保存当前完整原型文件与资产引用，包括本地未提交改动，不能只把最近一次提交当作 V19。
2. 固定 C、painted、quiet，以及完整/轻过渡两个观察条件。当前 `v` 参数只是版本标记，共用同一实现；版本对照需使用保留的文件版本或独立试验开关。
3. 通过独立本地副本或明确控制单项试验的内部开关保留原版。比较控件留在原型工具中。
4. 固定相机视角、文章身份、模式、字体加载状态与截图时刻；比较静态排版时使用相同静止环境，检查动效时再开启环境微动。
5. 记录浏览器实际 `innerWidth`、`innerHeight` 和显示缩放，避免把设置窗口的物理尺寸误记成 CSS 视口。

代表性状态：房间初始、穿窗后首屏、文章在暗天空前、文章在亮云前、选星简介、阅读后有关系理由的简介、短文、长文、广角、时间模式。

交付：一份基线记录和可重新打开的本地对照；不要求复制全部项目或搭建新的应用框架。

## 4. 工作包 1：先修复简介与操作

### 4.1 简介拆成三个区域

保持当前无框、夜色渐隐的外观，内部结构调整为：

| 区域 | 内容 | 行为 |
| --- | --- | --- |
| 顶部 | 日期、关闭按钮 | 始终可以找到关闭动作 |
| 中部 | 分类、标题、引言、已显露的关系理由 | 内容过长时在这一处滚动 |
| 底部 | 简短状态与“进入阅读” | 留在可见区域，不随中部文字滚出 |

具体处理：

- 让中部承担唯一的简介内容滚动；关系理由并入同一滚动区，避免在简介中再嵌套一个小滚动框。
- 状态头和动作区预留固定的最低高度。现有 42dvh 可作为视觉占比对照，但不能让整个简介一起滚动而把按钮藏起来。
- 手机上的初始参数：外侧左右各 16px，内容左右各 20px；动作按钮高 44px，文字区到动作区间隔 8–12px。
- “进入阅读”可尝试 104–112px 的宽度。即使画面中的按钮看起来轻巧，其热区仍完整。
- 保留局部柔和渐隐来隔开文字与背景；若需要滚动边缘提示，使用轻微渐隐，不恢复硬边卡片或毛玻璃面板。
- 简介滚动、点击关闭、点击阅读时，背后天空不应随之拖动或缩放。
- 重排结构后同步核对显影遮块的定位、裁切和清理，防止遮块盖住操作区。

### 4.2 标题与紧凑布局

- 360px 以下的视口先试 22px 标题，字距 0–0.5px；较宽手机先试 23–24px。楷体风格继续保留。
- 常见标题的两行尽量均衡，避免末行仅一字；不要为某篇 mock 文章手工固定一个仅适合当前宽度的换行。
- 较长标题允许自然增加行数，由内容区域承接；完整标题可以查看，不以缩成难读小字或截断关键信息换取按钮可见。
- 正常竖屏优先保持下方简介、上方目标星的关系。需要将更多内容放进简介时，优先让中部滚动。
- 横屏可用高度不超过约 500px 时单独检查。若底部简介已无法容纳头部、内容和动作区，则采用右侧简介试排，宽度约占 44–48%，左侧留给目标星；这项布局需通过实测后确定。
- 简介与导航、目标星、边缘方向提示分别保留可用区域。真实触控测试要检查靠近屏幕边缘的控件。

### 4.3 操作热区与焦点

- 常用按钮以至少 44×44 CSS px 为本项目的舒适触控目标：关闭简介、关闭正文、返回上个停靠点、回窗边、模式切换、星图控制及边缘导航。
- 文章星已有约 44×44px 热区，继续保留；先检查它和附近控件的重叠，再决定是否需要单独调整。
- 同一组相邻控件先试 8px 间隔；视觉图形可以只有 16–20px。
- 手机上为“模式＋返回”提供足够宽度的一行。次级巡视控制与星图形成一组；若放大热区后拥挤，先调整分组和局部位置。
- 键盘焦点保持可见；关闭内容后回到原来的触发对象。焦点样式应清楚但不形成大片亮框。

验收：

1. 在 320×568、342×740 视口中，常见及长标题简介稳定显示后，不滚动文字就能点击关闭和阅读。
2. 加入较长引言、三条关系理由后，按钮仍在可见区域，全部文字均能阅读。
3. 《给未完成的事留一扇窗》不再出现原有末行单字问题；其他标题没有因修复它而溢出。
4. 实际命中区域不重叠，触碰动作区不会选中背后的星或触发天空手势。
5. 移动中反复点星仍然不会误开正文；到位后的主动点击可以正常进入阅读。

## 5. 工作包 2：字体、间距与阅读规范

### 5.1 建立小而明确的文字层级

以下是试排参数；最终应按实际字体观感校准，而不是逐项机械放大。

| 用途 | 桌面起点 | 手机起点 | 说明 |
| --- | --- | --- | --- |
| 正文标题 | 32–36px，约 1.5 倍行高 | 26–28px，约 1.5 倍行高 | 保留楷体气质，检查长标题 |
| 简介标题 | 28px，约 1.55–1.6 倍行高 | 22–24px，约 1.5–1.6 倍行高 | 手机字距先试 0–0.5px |
| 正文 | 16px，约 2–2.1 倍行高 | 16px，约 1.95–2 倍行高 | 当前基础合理，小幅比较即可 |
| 简介文字 | 14px，约 2 倍行高 | 14px，约 1.9–2 倍行高 | 提升当前手机 13px 文字的可读性 |
| 主要操作 | 13px | 13px | 配合 44px 热区 |
| 日期、必要提示 | 11–12px | 11–12px | 优先减少透明度叠加 |
| 关系理由 | 12–13px | 12px | 属于实际内容，不能按装饰处理 |
| 星旁标题 | 14–15px | 13–14px | 继续按需显露，验证标签避让 |

先沿用现有字体组合试排，核对中英混排、数字、标点和粗细。若跨系统差异明显，再选择可稳定交付的字体方案；字体文件的来源、许可与加载体积在采用前核实。

### 5.2 阅读层局部间距

- 桌面实际文字行宽先保持约 600–640px。
- 手机正文左右留白先保持约 24–28px；紧凑屏幕是否改为 22–24px 用相同文章对照决定。
- 桌面文章区域顶部内边距由 60px 试调至 44px，对照范围 40–48px。
- 引言分隔线上下间距由 30px 试调至 24px，对照范围 20–24px。
- 正文段后间距以 24px 为起点。避免一边压缩行距，一边扩大段距造成新的节奏不均。
- 顶部栏和底部栏随着文字变大重新量取高度，不能因辅助信息扩大而持续挤占正文。
- 正文滚动区可以滚至最后一行和文末关联；顶部返回动作稳定可见。

### 5.3 色彩角色与对比

- 延续纸色约 `#E9E7DE`、正文蓝灰约 `#34485E`、主要夜空文字约 `#EDF1EC` 的方向。
- 明确“主要内容、次要信息、可操作、禁用、装饰”五类呈现。可操作但未选中的按钮不应看起来像禁用。
- 检查文字颜色透明度与父容器透明度的叠加；先纠正必要文字被重复压暗的问题。
- 普通功能文字按至少 4.5:1 对比度检查。背景是天空时，覆盖亮云、暗天空、地平线等代表性状态；局部柔和承托可以比全屏压暗更合适。
- 装饰星、云与纯装饰线不套用正文对比度标准，但承担导航信息的图形必须可辨。

### 5.4 图标与文案

| 动作 | 建议表达 |
| --- | --- |
| 进入阅读 | “进入阅读”＋右向箭头 |
| 返回星空 | “返回星空”＋左向箭头 |
| 回到房间 | 房屋图标，可访问名称“回到窗边” |
| 返回上个停靠点 | 弯箭头，可访问名称说明具体返回行为 |
| 取消/关闭 | 统一线宽的关闭符号 |
| 正文结束状态 | 将“已抵达文末 · 关联理由已显露”简化为“已到文末”，由关联内容的出现提供反馈 |

阅读判定与已有关系理由保持原有含义，文案调整不增加停留时长或理解程度要求。

验收：在正常浏览器缩放下必要提示可读；200% 文字/页面放大时内容可达、控件可操作；最长标题、中英数字、无引言、长关系理由都能正常排版。浏览器缩放与文字放大应分别记录，不混为同一种测试。

## 6. 工作包 3：文章星与探索层级

### 6.1 先改善辨识，再决定背景改动

1. 固定四个测试画面：暗天空前的普通星、亮云前的普通星、重要星/珍藏星、选中星与邻星。
2. 保留普通、重要、珍藏星等及个体差异。先对文章光核做小幅试验，可从当前强度的 1.1 倍起步，必要时比较 1.2 倍；外部光晕先保持现状。
3. 保留背景星细弱、文章光核清楚、选中星反馈明确的层级。不要把所有文章做成同样明亮的主星。
4. 对亮云背景先检查局部对比；需要时调整云层局部亮度或未遮挡部分的星光强度。
5. 云在前、星在后的遮挡关系继续成立。云完全遮住的星不强行画到云前，也不通过出现常亮边框来破坏空间感。
6. 工程上优先利用现有遮光与渲染信息；避免为了亮度自适应新增昂贵的逐帧整屏回读。只有简单调整收益不足时才评估更复杂的实现。

### 6.2 停靠构图与邻星

- 桌面选中星的屏幕位置可以从横向约 35–45% 区域试排，与右侧简介形成关系；实际由当前朝向、可见邻星和遮挡情况校准。
- 手机以选中星位于简介上方的安全区域为目标，避开顶部导航与星图。
- 若相邻文章本来就近且不破坏明显的靠近感，可比较宽约 5–10% 的最终停靠视野，观察是否能保留一两颗邻星。
- 邻星本来很远时，使用已有边缘方向提示引导；不为凑画面临时移动已分配的文章位置，也不伪造内容关联。
- 普通探索继续以约 3–6 颗为画面参考，不强制每帧计数；广角总览单独判断。
- 检查星旁标题、简介标题、导航之间的避让。对手机上明显重复且拥挤的标题，先处理位置，再比较只在靠近/聚焦时短暂显示星旁标题的方案；文章身份仍须清楚。

### 6.3 窗边提示只做有依据的增强

- 保留当前无文字入口和间歇星尘作为基线。
- 如观察发现确有误认静态插画的情况，试验首次约 4–6 秒未操作时播放一次稍明显的沿窗微光，持续约 0.8–1.2 秒后回到现状。
- 任一进入、手记操作或离开房间会结束这次引导；当次返回不反复催促。减少动态时使用静态线索。
- 若当前提示已足够，不新增强化效果。观察过程可记录首次操作对象、是否尝试点击月亮、是否主动找到窗口；不把小样本结果包装成转化率结论。

验收：在原始显示尺寸和相同视角下，对文章星的辨识改善可见；厚涂、遮挡和大片暗部仍然成立。对照中没有收益的增强可以舍弃。

## 7. 工作包 4：连续探索、动效与模式提示

### 7.1 保留首次体验，简化重复呈现

| 场景 | 计划 |
| --- | --- |
| 首次穿窗 | 以当前约 2.5s 为基线 |
| 当次首次完整查看某篇简介 | 以当前约 2.8s、白块停顿约 0.5s 为基线 |
| 当次再次查看已完整显露的同篇简介 | 比较约 0.6–0.9s 的短呈现，先试 0.7s |
| 阅读后关闭正文 | 恢复原视角与简介，沿用已有返回体验 |
| 返回窗边 | 以当前约 2.6s 为基线 |
| 轻过渡 | 沿用现有约 0.18–0.22s 的短淡入/淡出路径 |

“简介已看过”只记录在当前访问内，使用稳定文章身份识别，与“阅读到文末”区分。只有简介文字完整显露后才记入；中断、取消或切到另一篇不应提前标记。刷新后不延续此标记。

切换关联/时间模式仍识别同一篇文章；已展示过的简介可以复用短呈现。相机是否到位与文字动画是否结束分别管理，不能因短显影结束就提前开放阅读。

### 7.2 主要动作与运动状态一致

- 按钮在布局中预留位置，靠近时显示明确的不可用状态。
- 相机到位后，“进入阅读”应及时成为可见、可操作的动作；不再因底部区晚显而额外隐藏一个已经启用的按钮。
- 同一目标移动中重复点击仍直接忽略，不缓存为之后自动打开正文的操作。
- 手动中断、改选文章、返回窗边、旋转屏幕时，遮块和过渡状态要正确清理。
- 阅读展开/关闭动画期间保持手势隔离；减少动态设置和显式轻过渡均需覆盖。

### 7.3 时间模式的小幅表达试验

- 在切换到时间模式并落位后，短暂显示当前位置的年份/月份，停留约 2–3 秒后淡出；主动聚焦相关节点时可再次看见日期。
- 首次试作只增加一个清楚的当前时期标记。确有需要时再比较相邻一两个时期，避免新增密集时间轴。
- 年月直接来自文章日期，时间相邻不暗示内容相关；图例与实际连线含义一致。
- 模式切换始终保留当前文章身份，返回路径继续可理解。

验收：连续选不同文章、取消后重选、跨模式回到同文、移动中改目标、阅读返回等操作中，按钮显隐和可用状态一致；没有残留白块、误开正文或重复入场。

## 8. 工作包 5：美术收尾与综合验收

### 8.1 配色与字标只做小范围对照

- 在布局、字号和星光确定后，再比较当前蓝色与远云稍偏灰蓝的版本。
- 第一轮只调整远云的饱和度/局部对比，起点可为小幅约 5–10% 的处理；具体依实现的调色参数定义记录，不把不同算法的百分比当作同一量。
- 月亮暖金、房间暖灯和浅色纸页作为稳定参照；比较亮云、暗天空、地平线、天顶四个视角。
- 小尺寸英文标志先比较减少细弧与微小装饰、保留双行主要字形的版本；仅在小屏清晰度更好时采用。
- 白色显影遮块继续保留当前版本。灰白、柔边方案属于可选审美对照，不能自动替换已选择的效果。
- 个性化房间物件安排在后续有真实素材时处理，不纳入本轮完成条件。

### 8.2 验收矩阵

| 维度 | 重点样本 |
| --- | --- |
| 紧凑手机 | 320×568、342×740 CSS px |
| 常规手机 | 390×844、430×932 CSS px |
| 横屏 | 568×320、844×390 CSS px |
| 桌面 | 1123×631、1440×900 CSS px；必要时补大屏 |
| 字体环境 | 当前 Windows 浏览器；能获得的 Android 与 iOS 实际字体呈现 |
| 内容长度 | 短标题、当前失败标题、约 20–30 字标题、中英数字混排、较长引言、无引言、三条较长关系理由 |
| 阅读内容 | 短文、长文、图片与长链接等代表性正文样本；不据此宣称正式内容已迁移 |
| 状态 | 房间、首次简介、重复简介、阅读后简介、正文、手记、关联/时间切换、广角、返回 |
| 输入 | 鼠标、键盘、真实触屏；单指与双指分别记录 |
| 显示设置 | 默认缩放、200% 页面放大、文字放大、完整与减少动态 |

执行方式：代表性屏幕走完整流程；其他尺寸集中检查布局与动作可达性，避免无意义地穷举所有组合。

必过检查：

1. 简介动作区与关闭入口可达，长内容不会把它们挤走。
2. 文本不横向溢出，完整标题和关系理由可以查看；缩放后仍可操作。
3. 44px 热区不会互相覆盖，也不会截获附近星体和天空手势。
4. 两次点星、移动中重复点击、改选和中断行为正确。
5. 正文内滚动不驱动天空；关闭后恢复视角和选中项。
6. 模式切换保留文章身份，时间信息与真实日期一致。
7. 星光、云、标题和命中区域仍对齐；遮挡没有失真。
8. 动效结束、中断、回窗及视口变化后没有遮块或透明覆盖层残留。
9. 没有由本轮改动引入的持续卡顿或持续布局抖动；如有性能疑问，在同设备、同视角记录前后数据，不预先宣称帧率达标。

布局与美术调整以实际渲染、测量和人工对照为主。自动检查集中覆盖容易回归的状态边界，以及按钮被裁切等关键问题，不给每个视觉数值各写一份重复测试。

真机无法取得时，记录具体未验证项目；模拟视口通过不能代替触控与实际字体验收。
