# 人物原地步行补帧

日期：2026-10-08。作者指出参考帧跳切仍然一卡一卡，要求提高帧率、增加动作过渡。此文件保留补帧阶段的实现和测量。作者随后认可帧率，但指出上下身清晰度不一致及腰部断层；当前实现与验证以[轮廓修复记录](silhouette-walk-edge-20261008.md)为准。

## 改动

- 原参考图集仍然保留；其中 17 个录屏帧主要是迈步、后脚抬起和换脚三组姿势。直接提高这些帧的播放速度不能补出缺少的动作。
- 从参考姿势标定髋、膝、踝位置；脚踝轨迹采用连续曲线，在相邻参考姿势的腿长约束下计算膝盖位置。摆腿完成抬脚和前摆，支撑脚的鞋底留在同一地面。
- 上身及衣摆使用参考像素；连续腿部轮廓用参考裤装的白色纹理蒙皮，鞋子使用完整中立姿势裁片统一旋转。腿部不直接交叉淡化，避免出现多条半透明腿。
- 首次启用时生成并缓存 68 个不同姿势，以 120 Hz 的取样密度供屏幕刷新选帧；在 60 Hz 屏幕上每次刷新均能选到新姿势。缓存后每次仅绘制一个裁片。
- 一轮仍为 17 / 30 秒，约 0.567 秒；原步速、头部水平位置、面板排布及静态 PNG 沿用。轻过渡和低性能回退、阅读及页面隐藏时暂停的规则保持。

## 验证

- 同一 120 Hz 刻度逐帧比较补帧前后的腿部像素：补帧前有 51 个近乎静止的间隔和三次明显跳切；补帧后 68 帧均产生变化，最大归一化帧间差异由约 85.3% 降为约 19.2%。见[帧间变化检查](evidence/silhouette-walk-smooth-20261008/smoothness-check.json)。此指标量化跳切，不替代人体结构的视觉验收。
- 对连续阶段取样检查腿长及支撑脚地面约束，误差均小于 1e-10 源图像素；参考中的腿长随姿势投影变化，各过渡保持对应的两段长度。
- 桌面 1440 × 900、手机 390 × 844、横屏 844 × 390 各取样约三秒，本机实际播放分别约 60.3、60.6、60.4 帧／秒。人物位置固定，头部横向变化不足 0.11 CSS px，画布边缘没有可见裁切，控制台无运行错误。
- 三种尺寸均验证轻过渡显示原静图、恢复后继续，页面隐藏及正文打开时停止绘制。见[浏览器检查](evidence/silhouette-walk-smooth-20261008/checks.json)。
- 68 个缓存姿势均不同，画布边缘无可见像素；本机补帧缓存生成约 11.4 ms，常态人物绘制平均约 0.04～0.05 ms。见[缓存帧检查](evidence/silhouette-walk-smooth-20261008/frame-checks.json)。
- Node 22.19.0、npm 10.9.3 下，26 项现有检查通过；新版本地预览和正式主题构建通过，各生成 148 个文件；`git diff --check` 通过。文章、星位和原始图片没有改变。
