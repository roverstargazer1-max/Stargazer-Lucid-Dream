# 冷色阅读切面（独立试稿，2026-10-02）

问题：如何让文章标题、简介和阅读层与当前深蓝星空属于同一个视觉世界，并减少楷体、米黄仿纸和古典装饰带来的模板感？

这是一套待作者体验的方案，并未应用到正式主题。它复用当前项目的真实文章《慢》、实时星空、窗边和阅读交互；只在独立的 4180 服务内追加这里的 study.css。没有修改文章、正式主题配色、字体或模板。

运行前先有新版静态预览，然后在仓库根目录执行：

```powershell
node .scratch/starry-blog/prototypes/cold-reading-20261002/server.mjs
```

- 正文切面：<http://127.0.0.1:4180/?motion=soft>
- 引言切面：<http://127.0.0.1:4180/?motion=soft&cut=note>
- 可关闭正文、进入阅读，也可巡视真实星空。试稿只用于判断这些样式，其他旧页面没有在本轮重设计。

设计：阅读底色 #111e2c；正文 #cbd6e2；标题 #e4ecf5；次级文字 #91a5bb。使用系统中文无衬线字，取消楷体和金棕色 UI 文本；保留原星空插画与字标。阅读层是稳定的深蓝灰平面，不加磨砂玻璃、霓虹、纸纹或假旧效果。去掉重复的长引言、装饰分隔线和仿古封印，保留原 Markdown 正文及引用结构，缩小元信息存在感。

正文每行约 38 个汉字，17px、约 35px 行高；手机 16px。冷白文字避免纯白刺眼，实体深色底避免云朵干扰长文阅读。引言继续留在天空里，日期、标题、正文入口都改为同一灰蓝白色系。

还没有得到作者对本试稿的批准；正式主题继续保留原视觉。截图会保存到本文件夹供复核。
