# 穿窗连续运镜修订

2026-10-12。作者反馈入场有画面空缺与变形，要求屋内推进、穿窗、转向星空、停稳的一镜到底效果。本地实现，未线上发布。

## 再次提速40%

作者在 4 秒版本上明确要求再快 40%。当前完整入场与回屋为 2857ms（4000 ÷ 1.4，取整到毫秒），相关显现时机同比缩短；同步运动、终点及柔和停稳沿用。轻过渡仍为 220ms，此项覆盖下方完整镜头时长。

3 项运镜检查和双主题预览构建通过；[桌面](faster40-desktop-summary.json)、[手机](faster40-mobile-summary.json)进出及检索往返通过，确认推进与转向重叠，空白、原画变形与天空额外变换计数为 0。[实际录制](faster40/capture-summary.json)采样 345 帧，原画倾斜和天空覆盖空缺为 0。最新版录屏为本地 `entry-faster40-preview.mp4`。本次未重跑完整套件或正式构建。

## 速度反馈修订

作者要求速度加快一些。该轮入场与回屋统一由 4800ms 缩短至 4000ms，速度提高 20%，同步运动曲线与落点沿用；轻过渡仍为 220ms。此项只覆盖下方记录中的完整镜头时长，后续时长以上方再次提速为准。

3 项运镜检查及双主题预览构建通过。[桌面](faster-desktop-summary.json)和 [手机](faster-mobile-summary.json)的进出及检索往返均通过，实际采样确认推进与转向重叠，空白、变形与天空额外变换计数均为 0。[新录制](faster/capture-summary.json)采样 510 帧，房间倾斜与视口覆盖空缺为 0，含落点采样的时长约 4.14 秒。新版录屏为本地 `entry-faster-preview.mp4`；下方录屏保留各版本历史。本次未重跑完整套件或正式构建。

## 节奏反馈修订

作者进一步要求靠近窗户时就同时转动，中间不暂停。本节记录同步曲线的实现，覆盖下方初次修复的分段时序；时长已由上述速度反馈修订更新，历史录制与汇总保留。

- 推进时长由 2600ms 延长至完整 4800ms，转向由 2300ms 后开始改为从起步开始；推进、前景侧移与天空转向共用同一平滑曲线，整个中段持续运动，末段一起减速。前景向左轻移至视口宽度的 10%，呼应天空右转；原画始终保持等比缩放，落点与素材沿用。
- 回屋同步反向运动，从任意探索视角连续接上；检索、导航与轻过渡逻辑沿用。
- [3 项运镜回归](../../../../tests/room-entry.test.mjs)在前版全部失败，本次全部通过：每个推进采样持续放大，每 100ms 的镜头深度和转角都持续变化，任意视角回屋连续；七种视口最终窗洞覆盖保持通过。
- [实际录制](overlap/capture-summary.json)：756 个采样帧、11 张截图，房间倾斜为 0，未出现天空覆盖空缺。新版实际录屏为本地 `entry-overlap-preview.mp4`；原 `entry-preview.mp4` 为初次修复的分段节奏。
- [六组浏览器汇总](overlap-regression-summary.json)：桌面、触屏模拟手机、横屏、途中调整窗口、持续帧压力下的实际低档，以及轻过渡的进出、检索往返均通过。完整镜头的五组采样均确认前景尚在时天空已移动；所有组的空白帧、原画变形与天空额外变换计数为 0。本次 3 项针对性检查、预览及双主题正式构建通过；初次修复的完整 89 项检查结果见下方，未在本次时序调整后重跑完整套件。

## 复现与原因

[capture.mjs](capture.mjs)录制实际入口、采样房间变换与天空覆盖范围。原版本运行 `node .scratch/starry-blog/evidence/continuous-entry-20261012/capture.mjs before` 失败：可见原画的 3D 倾斜系数最大 5.215，窗框发生明显透视扭曲。仅在测试浏览器取消房间倾斜／旋转、保留其余路径后，倾斜系数降为 0；结果分别见 [原版](before/capture-summary.json)和 [单变量对照](no-room-tilt/capture-summary.json)。

原镜头将整张平面房间原画逐渐侧转 60°、倾转 10°、放大并淡出，同时在真实天空镜头之外再旋转／缩放整张画布。文章星直到入场结束才绘制；房间退场后的蓝色空段增强了空缺感。本轮原版录制没有抓到透明天空帧，不将主观空缺感等同于清空画布。

## 初次修复实现（时序已被上述反馈覆盖）

- 房间只等比推进和平移，保持不透明，直到真实窗洞已覆盖视口；原画没有倾斜、拉伸或淡出。桌面和手机分别取原窗洞内的安全中心，透视增长只用于推进的等比缩放。
- 同一 4800ms 时钟驱动房间与天空。推进用 2600ms，2300ms 窗框已退出视野后开始 60° 天空转向；转向末段柔和停稳。房间采用原生动画播放，97 个采样帧近似同一平滑曲线，无逐帧 DOM 寻帧。
- 云、背景星与实际文章星连续绘制，亮度和星点大小不在开始时跳变；文章热区与导航等镜头停稳才启用。取消两处天空画布旋转规则及每帧临时缩放样式；原房间图、现有窗洞遮罩和天空素材保持原样。
- 回屋从当前探索视角起步，先转回窗边，房间再沿反向推进曲线进入视野。轻过渡仍为 220ms。过场隐藏固定旧版入口，结束后恢复。

## 初次修复验证

- [修订后录制](after/capture-summary.json)：可见房间倾斜系数为 0，天空保持覆盖视口，录制到柔和停稳。实际录屏保存在本地 `entry-preview.mp4`；PNG／视频按仓库规则不提交。
- [浏览器回归](regression.mjs)：桌面 1440×1040、手机 390×844、横屏 844×390、途中调整窗口、注入持续帧压力、手机轻过渡，六组进出及检索往返通过。逐帧采样画布四角与中心均不透明，房间没有 3D 倾斜；转向开始后的 9×9 窗洞采样没有前景遮挡，天空没有额外 CSS 变换；见 [汇总](regression-summary.json)。这些是浏览器采样与录屏，未测实体触屏或所有设备。
- [低档复核](pressure-summary.json)：确认进出均实际达到 `low` 绘制档；采样未发现空天空帧、画面倾斜或窗框残留，交互与图层清理正常。
- [回归测试](../../../../tests/room-entry.test.mjs)覆盖七种视口的窗洞覆盖、原画等比例、转向时机、平滑停稳，以及任意探索视角的回屋接续。`npm test`：89／89 通过；双主题预览与正式构建通过。
