2026-10-09，作者指出文末人物前脚露出进度条右端。

原定位把人物中心放在进度线终点，导致前半身超出线条。现在仅在接近终点时限制人物位置，为完整人物宽度和 2px 边距留出空间；开头和中段继续沿用原进度位置，百分比及进度线长度不变。静止图片和步行动画共用同一个位置边界，原人物素材没有裁切或重绘。

新版预览生成 160 个文件，29 项现有检查通过，`git diff --check` 通过。浏览器视口模拟检查了桌面 1440×1000、手机 390×844、窄屏 320×740、横屏 844×390 的 100% 终点：人物容器右边缘均位于进度线终点以内约 2px，没有横向溢出。桌面 0% 和 66% 的中心位置仍与原进度映射一致（偏差小于 0.01px）。没有实体手机验证或远程发布。
