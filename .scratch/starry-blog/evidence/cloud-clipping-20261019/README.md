# 云层长带与星盘悬停圆环修正

日期：2026-10-19。仅本地实现与验证，预览已重新生成；没有线上发布。

## 原因与修复

互动云原先根据中心及四个边缘点，把 PNG 拟合为一个平面变换。缩远并抬头时，位于侧后方的第三朵云下边缘接近相机平面，深度约 81.86，远小于中心的 555.24。1183 × 766 视口中，该云的纵向投影达到约 20,729px；旧实现只拦截横向超宽，画面外的云因此被外推回画面并成为长带。

现在先用云在穹顶上的四角及边缘中点做实际轮廓剔除，对接近裁切面的云保守剔除，并补齐纵向尺寸和非有限值检查。绘制按该轮廓裁切，鼠标与点按命中也检查同一轮廓，避免留下隐形的长条热区。既有 PNG、激活动效与静止时几何缓存继续使用。

星图检索入口删除产生浅白圆环的 `::before` 装饰及其悬停／聚焦规则。原悬停上移 2px、旋转 −4°、明暗反馈、按压与指针跟随继续沿用；键盘保留通用聚焦提示，系统减少动态效果时保持静态。

## 验证

- 修复前新增回归测试实际失败：云被拉成多个视口高；普通云的交互测试通过。修复后两项均通过，完整 `npm test` 为 **91/91**。
- 原截图复现视角：`yaw=1.365`、`pitch=1.24`、`zoom=.36`、原点观察，1183 × 766。仅画互动云时，顶部五分之一中透明度超过 10 的异常像素由 **81,502 降至 0**。
- 浏览器检查 **457 组**视角：1183 × 766、390 × 844、844 × 390；两档缩放、三档仰角（含正上方）、24 个方位，另含平移观察位置及原复现视角。每 12px 抽样实际云层像素并反算穹顶仰角，所有云范围上方的高空区域（大于 .60rad，留有轮廓近似余量）异常样本为 0。
- 实际云图的悬停、点按、触发后的移动、静止缓存像素一致性，以及阻塞状态下禁止点按均通过。
- 桌面 1440 × 900、手机触屏模拟 390 × 844、桌面减少动态效果设置均完成打开检索、展开索引、搜索“梦”与关闭返回。外围伪元素均为 `none`；桌面悬停实际旋转约 −4°，减少动态效果时为 0°；无脚本异常。
- 对 [原复现视角](shots/original-angle.png)、[接近天顶](shots/near-zenith.png)、[正上方](shots/zenith.png)及[入口悬停](shots/desktop-entry-hover.png)截图进行了目视检查。
- `npm run build` 双主题生产构建通过。正式源文件、`.preview/stargazer/` 与 `public/` 中两项修改的文件校验值分别一致；`git diff --check` 通过。

运行环境：Node.js 25.7.0、本机 Playwright Chromium。手机为浏览器触屏模拟，没有代替实体设备或线上部署验证。浏览器检查等待入口入场动画结束后再测悬停，避免把入场姿势误判成悬停终态。

## 重跑

在仓库根目录执行；浏览器脚本要求正常预览服务已经运行。

```bash
npm test
npm run serve:starfield
```

在另一个终端运行：

```bash
node .scratch/starry-blog/evidence/cloud-clipping-20261019/browser-check.mjs
npm run build
```

可以通过 `PLAYWRIGHT_MODULE`、`CHROMIUM_PATH` 和 `STARFIELD_TEST_URL` 调整本机路径与预览地址。简明结果保存在 [browser-summary.json](browser-summary.json)，截图按仓库约定仅保留本地。
