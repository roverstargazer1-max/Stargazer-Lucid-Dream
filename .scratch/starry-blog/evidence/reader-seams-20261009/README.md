# 文章底栏接缝调整

日期：2026-10-09。作者指出文章底部进度栏左右两侧的蓝色块、白色直边与正文衔接突兀。

## 调整

- 原底栏使用独立的 `#1435e2` 边框和 `#075ac0` 垫底，与正文原图中的蓝色侧栏有色差。改为继续显示同一张 `sheet.webp` 与 `continuation.webp`，按正文实际宽度及当前可见下边缘定位，滚到不同区域时也能衔接。
- 原来的 9px／手机 5px 边框尺寸并入内边距，进度栏位置和尺寸沿用，轨道、小人和百分比的计算不变。
- `progress-track.webp` 放在独立的装饰层，以样式遮罩隐藏左侧原图的青色／白色直边并淡接右端。进度线、人物与文字单独显示，不被遮罩裁掉。原 PNG、WebP 和转换工具均未修改，没有新增素材或 SVG。
- 背景宽度和偏移只在数值变化时写入底栏样式；不写入页面根节点，静止阅读时不重复写入。

## 验证

Node 22 下 29 项现有检查通过，新版预览生成 160 个文件，`git diff --check` 通过。

浏览器检查桌面 1440 × 1000、手机 390 × 844、窄屏 320 × 740 和横屏 844 × 390，覆盖文章开头、中段及文末。背景宽度及偏移与正文视口一致，没有横向溢出；人物中心与按进度计算的轨道位置一致。手机为浏览器视口模拟，没有使用实体手机。

同一桌面首屏 JPEG 截图中，在左右边缘 7 个采样点比较接缝上方 y=909 与下方 y=915 的 RGB 差值绝对值之和：调整前为 47–63，调整后为 0–9。此为截图采样，包含纹理变化及压缩误差，用于核对原来的直边色差；不代表全图每个像素均相同。
