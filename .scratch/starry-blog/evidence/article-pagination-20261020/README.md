# 文章文末时间导航

日期：2026-10-20。作者要求增加“上一篇／下一篇”，按发表时间连续阅读，并与当前蓝色星月文章页统一。

## 实现

- 在正文和作者确认的文章关联之后生成导航，展示方向、真实标题与发表日期。上一篇更早、下一篇更晚，首尾省略不存在的方向；单篇站点不生成空导航。
- 导航与星空索引共用发表时间及内部文章身份的排序键，不受置顶、更新时间、标签或检索筛选影响，排除未发表文章。
- 桌面左右并排，520px 及以下上下排列。沿用现有蓝色原图、标题字体、青色发丝线与文字层级；箭头在悬停／键盘聚焦时轻移 3px，标题提亮，减少动态效果时取消位移。每个链接的点击区域高于 44px，长标题可完整换行。
- 普通点击先取得目标正文，再更新地址并在当前窗口换篇，复用现有聚焦开合、播放器暂停和进度重置；前进后退能切换文章，关闭连续阅读时一次回到原入口。修饰键和无脚本访问沿用原生链接。
- 失败时保留当前文章、地址与滚动位置并允许重试；加载期间关闭窗口会取消本次换篇。文末导航不计入正文阅读进度。
- 按作者后续红框反馈收紧上下留白：桌面导航上边距由 48px 减至 32px，底部内边距由 64px 减至 48px；窄屏上边距由 32px 减至 24px，手机底部内边距由 50px 减至 32px。字体、导航内部间距及交互沿用。

- `npm run build`：新版与 Kira 双主题生产构建通过；本地双主题预览已更新。
- `node --test tests/dual-theme-build.test.cjs`：2 项通过，补充验证 Kira 作为默认主题时，导航仍指向 `/starfield/` 下的正确文章。
- [浏览器复测脚本](verify.cjs)与[结果摘要](browser-summary.json)：1440、1024、768、390、375、320px 视口、844 × 390 横屏、系统减少动态效果和轻过渡共九组条件通过；均检查无横向溢出、导航不被底栏遮挡、点击范围、窗口内换篇、进度归零、前进后退与关闭。脚本异常为 0。
- 补充检查从归档连续阅读三篇后关闭可回到原清单、请求失败后原文与地址／位置不变及重试、请求未完成时关闭不会重新打开阅读窗口、320px 长标题排版、关闭 JavaScript 后的原生链接。
- 已目视核对 [桌面](desktop.png)、[手机](mobile.png)和[窄屏长标题](narrow-long-titles.png)截图；完整截图按仓库约定保留本地并忽略。
- 留白微调后重新生成双主题预览，并核对 [桌面](desktop-spacing.png)、[手机](mobile-spacing.png)及[间距实测](spacing-summary.json)，两端上下空隙均缩小，无横向溢出，文末进度保持 100%。

使用本机 Chrome 无头浏览器和运行时 Playwright；通过 `NODE_PATH` 提供 Playwright，`STARFIELD_BROWSER_PATH` 可指定已安装浏览器。预览默认地址为 `http://127.0.0.1:4175`，可用 `STARFIELD_PREVIEW_URL` 替换。真实手机硬件与线上部署未在本轮验证；本轮完成本地实现、预览与生产构建，未发布线上。
