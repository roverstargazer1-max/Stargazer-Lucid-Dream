# 星盘入口的无损缓存

入口实际为 60–100 CSS px，却下载两张 1254 × 1254 PNG，共 3,318,207 字节。本次保留原始 PNG 发布地址及全部裁切、轴心、旋转与悬停几何，仅将运行时引用换为同尺寸的无损 WebP：盘面 1,077,910 字节，局部修补 100,350 字节，共 1,178,260 字节，减少 2,139,947 字节（64.5%）。

局部修补图只在既有 `repairClip` 内显示，缓存将该区域外加 64 原生像素余量之外的像素置透明；保留原画布大小。其余可见像素不改，盘面全部像素不改，ICC 信息保留。生成器会检查 WebP 解码后逐像素一致。更换原图或修补区域时运行：

```sh
python3 themes/stargazer-starfield/tools/prepare-entry-art.py
node .scratch/starry-blog/evidence/performance-20261019/entry-pixels.mjs
```

生成缓存已提交，日常构建无须 Python/Pillow。原图仍由原路径逐字节发布，既有自动检查继续验证它们。

浏览器对原 PNG 与新缓存做 96 组截图字节比较：DPR 0.75／1／1.5／2，入口边长 60／72／100，水平方位 0／0.8／π／5.7，并覆盖悬停。全部一致，见 [像素摘要](entry-pixels-summary.json)。这里只声称入口图片下载量和像素结果；整体首屏速度仍由完整流程测量判断。
