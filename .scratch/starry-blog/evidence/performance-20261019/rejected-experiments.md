# 未采用的动效试验

## 暂停的 ::backdrop 原生动画轨道

候选以伪元素上的暂停原生动画替代每帧样式表规则更新，试图减少阅读／检索背景的样式计算。已生成伪元素的静态 fixture 中，32 组计算样式对照通过，初步开合采样也显示阅读样式耗时较低。

但实际应用在 dialog 关闭时就创建控制器。完整生命周期测试发现：带 `?motion=soft` 且系统偏好减少动态效果时，正文打开后的背景仍为 2.4px 模糊，原实现应为 0px；实际动画列表中没有候选的伪元素轨道。仅在已打开的 dialog 上验证不能证明完整生命周期正确，原先较少的工作也不能作为等效视觉下的性能收益。

因此该候选全部撤回，阅读与检索继续使用原规则，不修改模糊、曲线或开合节奏。`candidate-b` 是该被拒试验的完整流程，不能当作最终优化版。初步 fixture 和对照原始 JSON 只留本地，以 `*-rejected.json` 命名，不作为成功摘要提交。`lifecycle.mjs` 保留对真正应用中的正常／轻动效背景模糊、开合、重访及窗口变化的断言，防止类似假阳性。
