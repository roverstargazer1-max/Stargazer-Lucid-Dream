# 阅读人物静止与滑动一致性

2026-10-09，作者指出静止与滑动时人物换了造型，大小也不一致。

## 原因与复现

阅读栏静止时显示 `reader/walker.png`（95×148），滑动时改为 `silhouette-walk-frames.webp` 中的 280×390 姿势。两者本身不是同一人物轮廓，并分别经过图片适配和图集绘制。以桌面 52.15625×73.0234375 的容器、透明度至少 128 的像素统计，静止图可见高度约 71.05px，图集首帧约 64.64px。

最小复现直接调用实际的 `createSilhouetteWalker`：开始步行、推进到一帧、暂停，再恢复；检查人物显示入口、图集绘制区域、暂停期间绘制次数与恢复帧。Node 22 运行 `node --test tests/silhouette-walker.test.mjs`，修复前两次均为 3 项失败、1 项通过，首项明确失败于“停止时应继续显示同一人物”；修复后 4 项通过。

## 调整

- 阅读栏开启 `freezeWhenIdle`，从首次静止起就显示同一个图集。停下后保留最后一帧；再次滑动从原姿势继续，暂停时间不计入步行时间。
- 静止与滑动共用白色处理、缩放和落脚基线；静止时调整窗口大小也会重绘当前姿势。相同尺寸和帧的暂停状态不重复绘制。
- 移除阅读栏另一张静态人物的显示入口。图集尚未载入时等待原素材，避免先出现不同的人物；减少动态时保持图集静止姿势，进度位置继续更新。
- 观测面板的静态回退沿用原行为；本次没有修改图集、原 PNG、帧数、步速或终点边距，没有新增美术素材。

## 验证

`npm test` 生成新版预览 160 个文件，全部 33 项检查通过；其中新增 4 项覆盖停止与恢复、初始静止与暂停缩放、延迟加载、观测面板回退。`git diff --check` 通过。

浏览器检查桌面 1440×1000、手机 390×844、窄屏 320×740、横屏 844×390。初始、滚动后及停止时均显示同一图集的画布，同一视口内人物尺寸和落脚基线一致；100% 时人物容器仍留在轨道终点以内约 2px。位置与可见性记录见 [checks.json](checks.json)。

手机停下后两次截图，在人物附近 x=340、y=778、32×42 的区域比较 4032 个 RGB 通道值，差异为 0，见 [paused-pixels.json](paused-pixels.json)。此为实际静止截图的像素核对；启停时序、源帧及暂停不重绘由上述回归检查覆盖。
