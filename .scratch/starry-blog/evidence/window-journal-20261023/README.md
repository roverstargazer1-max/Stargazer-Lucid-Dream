## 实现

- 复用桌上本子入口；本子未完整处于视口时显示独立书签，避免手机和窄桌面裁切导致无法进入。星空右下角提供同一入口；关闭时保留原场景、当前月份与滚动位置，并返回入口焦点。
- 单张连续深蓝书页；月份与日子从新到旧，同一天按记录时间顺排。不要求标题和封面，日期精度保持原样，不经 UTC 换算。
- 打开 600ms，随入口方向轻移、缩放并展开，页边掠过一次微光；关闭 320ms，沿原方向轻收。换月出场 105ms、入场 205ms，轻微横向衔接。快速关闭可从当前动画姿态收回；连续换月采用最后一次选择。减少动态效果／轻过渡开合 140ms，换月 100ms，仅淡入淡出。
- 手记正文按需加载并复用；请求失败可重试或直达独立页。阅读时暂停底层星空微动，菜单先响应 Escape，第二次 Escape 才关闭阅读层。
- `source/_journal/*.md` 是实际写作来源，不进入文章星、文章检索和 Kira 文章列表。`published: false` 的记录在渲染前剔除。`/journal/` 提供静态正文和每则记录的独立锚点，支持无脚本阅读。
- 尚无作者日记正文；统一本地预览提供 9 则明确标记的虚构示例。新增真实内容后使用真实内容。正式构建不包含示例，当前显示等待第一句话的空白页。
