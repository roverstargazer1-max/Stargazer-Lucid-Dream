# 手机星盘移到左下方波纹区

2026-10-12，按作者截图的红框位置，将手机竖屏的星盘放到人物下方、“关联／时间”上方。取消观测面板出现时的 216px 上移；入口始终为 72×72px，左边距至少 14px，底边距至少 86px，底部安全区较大时使用安全区加 72px。同步修正两处样式注释。盘面、指针随视角转动、检索开合与桌面／短横屏位置沿用。

## 本地验证

`capture.mjs` 在 Chromium 中捕获以下视口；手机启用触摸模拟。脚本直接触发穿窗和选星作为布局检查的起始状态，再以真实点击／点按检查星盘入口，Escape 退出检索。

| 视口 | 星盘左上角 | 尺寸 | 与模式组的垂直间距 |
| --- | --- | --- | --- |
| 手机 390×844 | 14, 686 | 72×72 | 17px |
| 窄屏 320×568 | 14, 410 | 72×72 | 17px |
| 竖屏 450×875 | 14, 717 | 72×72 | 17px |
| 横屏 844×390 | 16, 306 | 60×60 | 模式组在顶部 |
| 桌面 1440×1000 | 28, 850 | 100×100 | 模式组在顶部 |

五种视口选星前后及退出检索后的星盘纵向变化均为 0px，中心点实际命中星盘，检索可以打开和退出，未收到页面脚本异常。桌面在选星后缩到 390×844，也回到手机左下位置。手机截图已人工检查：人物可见部分在星盘上方，星盘落于波纹区，不挡模式组或 READ；人物透明容器的包围盒与星盘热区存在交叠，不作为原图可见像素重叠的判断。

详细矩形和返回状态见 [browser-summary.json](browser-summary.json)。截图保存为 `mobile.png`、`narrow.png`、`reference.png`、`landscape.png`、`desktop.png` 与 `desktop-to-mobile.png`，按仓库约定仅保留本地。可在预览服务运行时，从仓库根目录执行 `node .scratch/starry-blog/evidence/mobile-astrolabe-20261012/capture.mjs` 重跑；浏览器依赖路径记录本机环境。
