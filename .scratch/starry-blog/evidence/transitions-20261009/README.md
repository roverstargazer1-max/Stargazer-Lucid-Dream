# 穿窗与回屋动画专项诊断（2026-10-09）

> 测试产物保存规则（2026-10-09）：本记录保留结论、复测代码及摘要；详细报告、逐次 JSON、截图和录像仅在本地归档，相关链接对应本地文件。历史数据仍在原提交中。见[保存约定](../README.md)。

针对用户录屏中的第一次穿窗和返回屋内卡顿。此前的性能检查采样的是动画完成后的稳定画面，不能回答这两段过场是否流畅。本次测量直接覆盖点击后的整个过场，保留原素材、镜头曲线、五个房间关键帧、模糊效果和时长：穿窗 1900ms，星空落地 2500ms，回屋 2600ms；柔和模式仍为 220ms。

## 复现与定位

基线为 `7047cb1` 的预览产物，冻结在本机临时目录，由相同的无缓存预览服务器提供。实际打开 Chromium 窗口后，首次穿窗捕获到 116.1ms 帧间隔（`baseline-visible.json`，4 倍 CPU 限速）。12 倍限速的最小复现捕获到 81.5ms 停顿、62ms 长任务和持续丢帧（`constrained-baseline.json`），性能断言失败。首次加入截图的绘制追踪会额外增加拷贝成本，其 351.9ms 结果只用于诊断，不作为性能对比数字。

先建立专项浏览器反馈循环，再逐项对照：

1. 根节点样式影响隐藏文章：将相同动画变量临时限制在画布上，样式计算明显下降。源码确认 `--entry-bank`、`--entry-scale` 写在 body 上，未被使用的 `--sky-clarity` 也逐帧更新；返回时还有不被对应 CSS 消费的变量写入。
2. 插画模糊或插画本身：分别关闭模糊、隐藏插画做对照，未解决主要耗时，因此保留原插画和模糊。
3. 首次动态绘制：只预绘制静态镜头，没有覆盖镜头变化后的两个场景绘制缓存。预跑动态绘制的对照移除了首次长任务。保留 16ms、32ms 两个镜头采样作为初始化准备，最后恢复原窗口镜头，首屏原插画仍先显示。
4. 房间播放方式：暂停 Web Animation 后每帧改 `currentTime`，让房间效果依赖主线程逐帧同步。改为按原关键帧和同一时间原点原生播放；回屋反向播放，调整窗口时沿原始时钟继续。阅读交互仍保留可拖动的暂停时间轴。

还移除了过场中不可见星星的坐标写入和障碍物测量。这些测量发生在动画样式写入之后，会迫使浏览器同步计算布局。到达后照常恢复文章星星的位置、遮挡检测和附近标题。

所有生产改动仅涉及 `app.js`、`motion.js`、`painted.js` 和一条画布图层准备样式。未修改或生成图片/SVG，未改变绘制精度、镜头算法或背景质量档位。

## 三轮交替对照

同一台 Mac、Chromium 149.0.7827.55、实际浏览器窗口、12 倍 CPU 限速。桌面 1680×970，手机模拟 390×844；两者 DPR=2，手机启用触控。每轮新浏览器和新上下文，分别冷页面访问并测首次进入、首次返回；基线和优化版本交替运行，各三次。数字为三次中位数，所有样本均为 `full` 画质、WebGL 渲染，无页面错误。

| 过场 | 帧间隔 P95：之前 → 之后 | 样式计算总耗时：之前 → 之后 | 主线程占用：之前 → 之后 |
| --- | --- | --- | --- |
| 桌面进入 | 33.7 → 17.6ms | 886.9 → 339.4ms | 85.9% → 54.6% |
| 桌面返回 | 33.4 → 17.6ms | 1186.1 → 297.6ms | 76.1% → 43.9% |
| 手机模拟进入 | 33.0 → 17.6ms | 914.4 → 260.2ms | 81.7% → 48.3% |
| 手机模拟返回 | 31.6 → 17.5ms | 1144.2 → 267.4ms | 72.1% → 41.0% |

原始区间保存在 `paired-baseline-{1,2,3}.json`、`paired-optimized-{1,2,3}.json`，汇总为 `paired-summary.json`。进入采样 2800ms、返回采样 2900ms。主线程指标包含驱动点击时的少量开销；P95 为 RAF 间隔，并非直接测量屏幕像素的呈现时间。

## 最终验证

- `npm test`：29/29 通过；新版预览和生产构建均生成 160 个文件。
- 专项真实浏览器回归（`regression.json`）：桌面、手机触控、两轮进入/返回、过场中调整窗口、柔和模式；动画运行、时长、原关键帧、完成后的图层清理与交互状态均通过。
- 4 倍 CPU 限速、实际窗口、完整画质，桌面与手机模拟各两轮进入/返回（`final-desktop-mobile.json`）：全部性能断言通过，8 段过场的 P95 为 17.4–17.6ms，最大帧间隔 17.8ms，首次回调响应 10.7–15.6ms；无超过 34ms 的间隔、无长任务、无页面错误。
- 原有阅读/触控/模式切换/回屋验证通过（`reading-regression.json`）；静止屋内及阅读时没有额外场景重绘。
- 首屏拦住应用脚本时仍显示已解码的原插画；关闭 JavaScript、应用模块失败、WebGL 不可用时仍保留可读降级页面（`transition-final-startup.json`）；直接文章降级检查通过。
- 本地预览实际穿窗和回屋，保存 `final-sky.jpg`、`final-room.jpg`。

12 倍限速用于放大瓶颈，不代表某款手机的真实性能。后续重复极限测试仍有一次桌面首次 83.4ms 峰值，超过专项断言的 80ms 上限（`final-stress-complete.json`）；这一结果保留为未通过的压力样本。其 P95 仍为 17.6ms、无长任务，第二轮及手机模拟均流畅。不能据此承诺所有设备零掉帧；实体手机 GPU、温度和录屏开销未被模拟。浏览器上下文虽是全新，系统 GPU 驱动缓存不能完全隔离。
