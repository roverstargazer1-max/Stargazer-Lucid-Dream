# 新版友链入口

窗边右下角及星空右下角增加“友链”轨道入口。采用既有冷白／青色细线、字型和真实星空底图；悬停或键盘聚焦时图标轻转、名称提亮。星空中与手记并排，文章提示和云层避让范围同时更新。

面板从入口方向轻微展开与收回，关闭后保留场景、方向、探索模式和焦点。使用原生对话框，支持 Escape、外侧点击、关闭按钮和 Tab／Shift+Tab 首尾循环；补齐了内置浏览器从首个按钮反向 Tab 时离开内容区的问题。打开期间停止背景探索动效与方向键控制；轻过渡及系统减少动态效果采用短淡入淡出。

9 位朋友继续读取 `_config.hexo-theme-kira.yml` 的同一份配置，名称、简介、顺序与链接不变，头像延后加载。普通链接支持新窗口和无脚本直达；`/pages/friends/` 复用同一列表及视觉，备用主题路径自动增加 `/starfield/`。旧 Kira 及文章内容沿用。
