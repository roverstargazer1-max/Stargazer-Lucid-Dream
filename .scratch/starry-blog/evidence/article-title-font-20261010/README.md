# 文章标题字体试用（2026-10-10）

采用作者提供的 `assets/字体/LxgwMarkerGothic-v1.003/fonts/ttf/LXGWMarkerGothic-Regular.ttf`，仅替换文章页主标题为 LXGW Marker Gothic Regular（400 字重）。正文、日期署名、星空标签继续使用原字体；标题尺寸、行高、间距及位置沿用。此项为效果试用，未发布。

本地转换为完整字库 WOFF2：3,179,616 → 1,236,064 字节。转换前后 Unicode 映射及编译后的字形数据一致，保留 15,288 个 Unicode 映射，现有全部文章标题没有缺字。网页字体与 OFL 许可随主题保存，构建不依赖字体转换工具。

验证结果：

- 新版预览构建成功，33 项既有检查通过；当前改名后的科技字形素材与生成 PNG 字节一致，兼容原目录名称。
- 10 篇文章直达页面均预加载该字体，首页不预加载；生成的字体文件与主题素材字节一致。
- 桌面 1440×900、手机 390×844、窄屏 320×740 中字体实际加载成功，标题无横向溢出。长标题在 320px 时自然换为两行，日期署名仍在其下方；桌面间距 12px，手机 8px。
- 桌面置顶文章及长标题、手机长标题的截图仅在本地归档。预览窗口已恢复默认尺寸。

复测：生成新版预览，分别打开置顶文章及《活在真实天空下，做半个君子》，核对字体加载、标题边界和日期位置。字体版本及替换说明见[主题字体记录](../../../../themes/stargazer-starfield/FONTS.md)。
