# 手记星空背景与独立链接按钮

日期：2026-10-23。作者要求使用当前星空中的一段画面，替换单调的手记底色，并支持上下无缝拼接；同时删除图中圈出的每则记录右侧箭头。本轮为本地实现，未线上发布。

## 实现与来源

- 来源为 `themes/stargazer-starfield/source/images/fallback-sky.webp`，即原星空画布的实际截图。裁切天空和云层，避开月亮与地面，避免纵向重复多个地平线或月亮。原图未修改。
- 桌面裁切框 `(1350, 0, 2450, 1220)`，手机裁切框 `(1740, 0, 2380, 1220)`。保留原画面笔触和颜色，首尾重叠 220px 作平滑混合，输出分别为 1100×1000 与 640×1000 的无损 WebP。制作过程是用户要求的原图裁切与拼接，没有 AI 重绘。
- 显示文件位于主题 `source/images/journal/sky-repeat-desktop-v1.webp` 和 `sky-repeat-mobile-v1.webp`，分别约 208KiB、118KiB。可用主题 `tools/prepare-journal-sky.py` 重建；正常构建只使用已生成图片。
- 正文使用 `repeat-y` 与 `background-attachment: local`，随实际滚动移动；标题区延续同一幅纹理，减轻外框并删除装订竖线。独立页外侧使用同一张原星空截图。
- 删除记录右侧箭头及其点击区、悬停与触屏占位，只在填写了时间时显示时间行；原记录 ID、直达锚点与无脚本阅读保留。内容模块和新建命令沿用。

## 核对

- 无损显示文件重新解码后与生成像素一致。首尾行三通道平均差分别低于 0.28/255，拼接处连接的是原截图相邻两行。详细裁切、尺寸和差值见 [texture-summary.json](texture-summary.json)。
- 六组浏览器检查通过：1440×1000、390×844、320×568、844×390、减少动态效果、轻过渡。均无横向溢出、脚本异常；按宽度正确加载对应底图，背景跟随正文局部滚动，记录箭头不存在。开合、连续换月、快速开关、焦点恢复、旧锚点直达与刷新、无脚本正文及失败重试均通过，见 [browser-summary.json](browser-summary.json)。
- 实际浏览器中观察了九月连续阅读、上下滚动和纵向拼接；本地截图为 `preview.png`，不随仓库提交。
- 原始像素逐点核对可读性：按最小 8% 遮罩、不计文字阴影计算，正文对比度至少 7.86:1，辅助文字至少 4.58:1。桌面排除所有文字栏以外的左侧 32px 星点，手机核对整幅纹理，见 [contrast-summary.json](contrast-summary.json)。
- 本地预览构建、双主题正式构建及完整 110 项测试通过；正式输出不含虚构手记，两个输出均包含新纹理且不再出现记录箭头。`git diff --check` 通过。
