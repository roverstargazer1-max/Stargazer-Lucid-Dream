# 通信卫星友链入口

按作者选择“通信卫星”的新要求，替换此前两个右下角常驻按钮。房间不再显示友链快捷按钮；穿窗后可在初始星空视野中发现插画卫星，点开原有友链面板。默认仅显示物件，悬停／键盘聚焦时轻微提亮、抬起并显示信号波和“远方的信号／友链”。手机直接点开，84px 最小宽度、56px 最小高度的点击范围保持可用。

卫星使用虚拟穹顶中的一个固定位置，与文章数据、编号、时间路径分离，位置和尺寸由当前镜头投影得到。转动视角时随天空移动；离开视野时整个链接与点击范围一并隐藏，不向屏幕边缘吸附。正文、检索和文章观测时收起。穿窗时才准备图片，房间首屏不请求；面板关闭后回到原卫星，窗口变化导致卫星不可见时恢复到回屋按钮。减少动态效果及轻过渡取消物件位移和循环信号。

内置 imagegen 以当前真实星空截图为配色／画风参考，生成了透明图稿，原图与完整提示词见 `assets/design/friends-satellite-v1/README.md`。发布的 384×256 WebP 为 74,592 字节，保留 alpha；仅等比缩放和编码。友链配置、9 位朋友及原有面板沿用。

验证：120 项检查通过，预览与正式双主题构建成功。新增检查覆盖初始桌面、手机竖屏与短横屏可发现性、热区、镜头不变、随视角移动和背向剔除；实际浏览器检查了房间无固定入口／图片未请求、卫星加载、手机尺寸点击、方向键转开与转回、面板打开期间保护镜头、关闭后恢复焦点和方向，以及桌面轻过渡表现。浏览器检查数据在 `browser-summary.json`，素材校验值在 `verification-summary.json`；临时视口恢复后保留原预览页。本地实现，未提交或发布。
