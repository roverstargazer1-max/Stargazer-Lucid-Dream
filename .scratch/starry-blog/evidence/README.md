## 保存约定

测试代码和简明结论需要随仓库保存；自动生成的大型报告与媒体产物从 2026-10-09 起按以下规则归档：

- 提交可重复运行的测试代码、复测脚本、Markdown 结论和 `*-summary.json` 摘要。
- 截图、录像、完整 Lighthouse HTML／JSON 报告、性能追踪、CPU 采样及逐次测量 JSON 保留在本地，由根目录 `.gitignore` 忽略。
- `tests/` 中的回归测试、正式主题素材、文章、设计规格和工单继续提交。此目录中的云算法基线等源代码也保留，用于重建正式素材和复测。

已有产物只退出 Git 跟踪，本机文件保留，旧提交没有改写。此调整减少后续提交内容及当前版本的文件量，不会清除旧提交中的大文件或自动缩小历史仓库。提交前的原始数据仍可从当时的 Git 提交取得。

各日期目录中的记录保留原测量环境、结论和限制。指向截图、录像、原始报告或逐次测量 JSON 的相对链接表示本地归档；新克隆的当前版本不自带这些详细产物，可按相应复测说明生成。`*-summary.json` 和源代码链接仍随仓库提供。

新增验证继续将产物写入相应日期目录，结论与重跑方法写入 Markdown；不强制加入被忽略的报告或截图。需要提供一个可独立复核的最小测试样本时，使用正式测试目录并在提交中说明用途。
