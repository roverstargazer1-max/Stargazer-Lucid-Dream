# 刺猬思绪引导与手机取景

日期：2026-10-21。本地预览为 `http://127.0.0.1:4175/`，未发布线上。

按作者要求在刺猬上方加入淡淡的内心独白。最终可见文案仅为 `try to click…`，取消解释行，泡泡缩为 142 × 80px；低矮横屏为 118 × 68px。沿用 LXGW Marker Gothic、夜蓝底色与冷白细线，用两颗小点连接刺猬，不叠加卡片、箭头或循环跳动。

泡泡是原生按钮，鼠标点击、触屏点按和键盘 Enter 均进入现有星空。悬停／键盘聚焦轻微提亮；开始穿窗即淡出，回屋后恢复；轻过渡与系统减少动态效果下静态显示。星空尚未就绪时禁用并隐藏。辅助阅读描述保留“每颗星，都是一篇文章”，不显示为第二行。

手机使用同一张原画，裁切锚点从 20% 调至 28%，向右取景。首帧内联样式、基础样式和场景样式同步修改，原图比例与穿窗运镜不变。泡泡位置随原画变化，并在窄屏限制右边界。

- `npm test`：103 项全部通过，包括按新裁切参数复核的穿窗几何检查。
- `npm run build`：双主题生产构建通过；新版 `/`、Kira `/legacy/`。
- 浏览器检查覆盖 1440 × 900、390 × 844、320 × 568、760 × 900、761 × 900、740 × 390、2560 × 1080 及 390 × 844 减少动态效果。泡泡和文字完整位于屏幕内，无横向溢出；实际鼠标／触屏点击、回屋恢复及原窗口点击均通过。桌面额外验证 Tab 和 Enter。
- 延迟主模块启动后，手机首帧与就绪后的房间位置完全一致；桌面与手机宽度往返调整、无脚本回退均通过。
