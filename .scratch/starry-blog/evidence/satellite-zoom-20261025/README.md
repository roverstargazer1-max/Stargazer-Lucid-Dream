# 卫星跟随镜头缩放

移除 JavaScript 中 84–112px 的显示尺寸限制，以及样式中会把图像撑大的最小宽高。卫星采用固定虚拟宽度，图像宽高来自同一镜头的焦距与深度投影；只给点击区域保留 44×44px 最小范围。天线信号与图像同步缩放，边缘裁切按照实际图像范围判断。当前发布素材为同一原图的 768×512 无损 WebP，以支持放大查看。

新增回归检查验证两种视口下 0.36–2.8 镜头倍率的连续尺寸比例与独立点击范围。123 项检查全部通过；预览与正式双主题构建成功。

在实际浏览器用滚轮验证：初始图像约 65×43px，放大后约 136×91px，最大约 323×221px，最小约 33×22px；最大状态包含悬停时的微小旋转。最小图像对应 44×44px 点击范围，实测可正常打开和关闭友链。检查数据在 `browser-summary.json`，截图为 `zoom-in.jpg` 和 `zoom-out.jpg`。

仅本地实现与构建，未提交或部署。
