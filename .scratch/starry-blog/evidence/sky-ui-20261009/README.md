> 测试产物保存规则（2026-10-09）：本记录保留结论、复测代码及摘要；详细报告、逐次 JSON、截图和录像仅在本地归档，相关链接对应本地文件。历史数据仍在原提交中。见[保存约定](../README.md)。

日期：2026-10-09。作者要求 Logo 再放大约 40%、标题随鼠标靠近显露、右侧按钮使用“右图标”素材，并去掉此前的测试说明文字。

## 最终实现

- Logo2 的宽度从桌面 264px、手机 192px、低矮横屏 152px 调整到 370px、270px、214px，增加约 40%。保持原 PNG 和比例；手机导航位于 Logo 下方，避免按钮与品牌链接的点击区域交叠。
- 文章星标题默认隐藏，鼠标／笔指针靠近星星 88px 内时淡入。移开或开始拖动后淡出；指针进入已显露的标题时可以继续点击它。键盘聚焦可显露标题，触屏点选显露已选星的标题，读后灰色沿用。
- `右图标/右图标.png`（147 × 89，RGBA）原样发布至 `images/branding/right-icons.png`。两个按钮分别通过样式显示原图中从 `(0,14)` 和 `(87,14)` 开始的 60 × 60 区域；没有生成或重画 SVG。桌面按钮 56px，间隔 14px；手机按钮 52px，间隔 12px；低矮横屏按钮 48px。图案的显示宽度分别为 40px、36px、34px。
- 删除可见手势操作提示、探索路径／文章关联图例及“星空里的旧入口”文案；空站页面也不再显示本地准备步骤。操作名称和读屏状态继续用于辅助访问。
- 仅更新真实文章主题，V20 原型独立保留。
