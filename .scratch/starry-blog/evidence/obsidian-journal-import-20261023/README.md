## 原文保留

- 不纠正错别字、不改写语句、标点、表情或中日英混排；正文的原有分段与软换行保留，继续使用现有手记的字体和段落间距。
- 文件名中的 `·` 仅作为时间分隔符，规范到 `date` 字段的 `HH:mm`；日期缺少前导零时只规范元数据，未补造时间。
- `2026.10.9.md` 正文开头独立的 `00:47` 移到日期字段，在原有时间栏显示一次；其后正文原样保留。
- 两个 Obsidian `![[图片名]]` 标记改为普通网页图片链接，显示原图片，不增加图注或替代文字；附件逐字节复制，未压缩、重绘或裁切。
- 导入前对所有正文逐一反向还原这两类显示格式调整，要求与原始字节完全一致；创建后核对原库文件未变。允许的尾部换行由既有新建接口补齐。

来源文件名、目标路径、日期精度、图片映射及 SHA-256 见 [import-summary.json](import-summary.json)。[import.cjs](import.cjs) 为本次显式迁移脚本：传入原库路径、严格识别日期、跳过留存文件，创建前拒绝覆盖已有目标，失败时回滚本次新建文件。重复迁移会停止，不会重复添加内容。
