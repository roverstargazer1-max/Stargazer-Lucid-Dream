# 手记图片按需展开与回到顶部

2026-10-23，按作者要求调整当前真实手记。本次只改变展示与交互；13 则 Markdown、原始图片和 Obsidian 内容保持不变。本地预览及正式输出已构建，未推送或线上发布。

## 行为

- 生成阶段仅在手记中把图片、`picture` 与 `srcset` 来源保存到惰性 `template`，普通文章沿用原样。页面初始没有活动的手记图片节点；悬停入口、获取手记 HTML、切换月份与滚动均不实例化图片。
- “查看图片”第一次点击才把对应模板实例化，请求原图，在正文原位置展开；加载中显示状态，失败显示“重试图片”。成功后可反复收起／展开，复用已经创建的图片。原有 Markdown 图片写法和顺序沿用；没有 JavaScript 时只提供主动查看原图的链接。
- 展开与收起使用短暂高度、透明度过渡；轻过渡及减少动态效果只用短淡入。连续点击以最后一次操作为准，关闭手记会收束未完成动画。
- 阅读向下超过 180px 时，在右侧留白显示细线回顶箭头，44px 热区；点击后焦点回到阅读区。弹窗只滚动手记，独立页滚动页面；完整动效平滑回顶，轻过渡与减少动态效果直接定位。在顶部隐藏，悬停／键盘聚焦时轻微提亮并显示提示，手机右侧为按钮留出正文间距。
