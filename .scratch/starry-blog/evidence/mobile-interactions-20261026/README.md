# 手机点击与交互检查

日期：2026-10-26。范围为当前新版个人博客的窗边、星空、检索、阅读、手记、友链、归档和标签清单，并检查新旧主题的同篇切换。本轮仅本地实现与验证，未推送或线上发布。

## 发现与修复

| 问题 | 复现与修复结果 |
| --- | --- |
| 检索筛选太小 | 390×844 原年份／星等按钮高 22.64px，宽约 35–38px；320×568 修复后均高 44px、宽至少 57px。沿用原稿图片，手机单独调整排布。 |
| 星图重叠热区读错文章 | 390px 下点 SLD-0001 中心，实际打开 SLD-0012；SLD-0003 中心也被 SLD-0007 覆盖。改为按点按位置选最近的有效星点，键盘仍读焦点所在文章；筛选排除的星点不拦截点击。两种筛选状态均实际点按复测。 |
| 从文章星起拖无法巡视 | 真实手势处理器回归在修复前失败。星点与空白现在共享拖动／双指路径，点按在抬起时判断，键盘独立保留。实际从星点中心拖动后星位移动，未选中、未打开正文。 |
| 检索退出被卷走 | 390px 原面板滚动 97px 后退出按钮 y=-53；退出按钮移出滚动内容。320px 修复后面板滚动 356.5px，退出按钮仍在 y=44，屏幕中心命中自身。 |
| 键盘与输入遮挡 | 手机打开检索、清除筛选时聚焦退出按钮，主动点输入框才开始输入；输入字号 16px、热区高 44px，并给放大镜留下独立空间。粗指针提交后收起输入焦点。 |
| 横屏索引过窄 | 667×375 原右栏约 141px，长标题每行只容几字。为横屏索引保留独立宽度，扩大筛选热区并保留图面内滚动。667×375、844×390 的筛选、收起和退出通过。 |
| 手记和全文索引无限等待 | 本地服务器故意不响应首次请求，原手记持续停在“正在翻开手记”。两条路径新增覆盖响应头与正文的 8 秒超时，取消卡住的请求，支持重试。手记点击“再试一次”后加载 13 则记录；检索点放大镜恢复全文索引。 |
| 全文索引失败连标题检索也不可用 | 全文准备中或失败时继续使用已有标题、标签、分类与星表号，提供正文检索状态。阻塞索引时查 SLD-0001 仍返回正确文章，重试后恢复“1 篇文章”。 |
| 清单短标题热区小、顶部入口换行 | 320px 标签页的短标题原高 27.2px；在原行留白内扩大到 44px。“旧版”入口保持 48×44px 与单行。点“慢”进入正文，关闭后回到原标签清单。 |

## 复测范围

浏览器视口：320×568、390×844、430×932、667×375、844×390；另在 1280×720 检查桌面兼容。

- 窗边思绪入口、手记入口、穿窗与回屋；完整动效及 `?motion=soft`。
- 点星、靠近时连续点按、到位后 READ、从星点起拖、模式切换。
- 检索年份／三种星等选择与重复取消、组合筛选、空结果、清除、索引收起、图面滚动后关闭。
- 星图重叠点按、筛选后点按、检索进入正文再返回原条件。
- 文章相邻导航、浏览器后退、关闭正文、文章直达及新旧版同篇往返。
- 手记换月、月份菜单、按需图片、回顶、合上；独立手记页换月与横向溢出。
- 卫星打开友链、单栏滚动、退出；实际点首位朋友确认另开页面并保留原场景。独立友链页 9 位朋友，无横向溢出。
- 归档／标签清单点读、正文关闭回到原清单。
- 人为阻塞首次手记／全文索引请求，检查超时、备用检索与点击重试。

本轮未再发现上述范围内明显值得继续改动的点击阻碍。浏览器验证使用尺寸模拟与屏幕坐标输入；双指与触摸取消由真实事件处理器回归覆盖，不能替代 iOS／Android 真机、软键盘及线上环境验证。
