# 电脑与手机主页原图统一

日期：2026-10-20。作者要求电脑和手机主页使用同一张图，基准为刚刚移除小猫挂件后的桌面原图。

## 实现

- 正式主题只保留 `scene.room` 和 `scene.window_mask` 两个共同资源入口：`room-poster-detail-v20.webp` 与 `room-window-mask-v17.svg`。
- 删除响应式 `<picture>` 原图切换、竖版遮罩、竖版窗口提示和竖版房间几何。两端原图保持 1672 × 941，手机等比铺满并以 20% 的横向位置取景，保留人物与相邻窗户。
- 首屏内联样式与完整样式使用相同几何；手机提示微光移入当前可见窗景。窗口及手记热区继续按共同原图坐标定位，穿窗镜头共用同一窗口落点与缩放。
- 旧竖版图片及 V20 历史原型素材保留，正式主页不再请求旧竖版房间或遮罩。

## 验证

- `npm test`：93 项通过。
- `npm run build`：双主题生产构建通过；本地双主题预览已更新。
- [浏览器复测脚本](verify.cjs)及[结果](browser-summary.json)：桌面 1440 × 900、手机模拟 390 × 844、小屏 320 × 568、断点两侧 760／761 × 900、横屏 844 × 390、减少动态效果、运镜途中桌面与手机尺寸往返，共 8 组全部通过。
- 每组核对同一原图与自然尺寸、同一遮罩、无横向溢出、实际鼠标／触屏点击窗口进入星空、返回房间及完整恢复，脚本异常均为 0；未请求旧竖版图或遮罩。
- 手机延迟主模块加载时，首屏与准备完成后的房间矩形完全一致。
- [两端实际页面截图对照](desktop-mobile.png)，左侧为桌面，右侧为手机模拟。完整截图保存在本目录并按仓库约定忽略。

复测环境为本机安装的 Chrome 无头浏览器与运行时 Playwright；真实手机硬件未验收。运行脚本时通过 `NODE_PATH` 提供 Playwright，必要时用 `STARFIELD_BROWSER_PATH` 指定已安装浏览器。
