- 复用既有 `silhouette-walk-frames.png` 的 68 个完整姿势，以白色显示。随滚动步行，停止后显示素材中的静止姿势；减少动态、隐藏页面或关闭阅读时停止步行，位置仍准确。
- 可复现转换工具：`themes/stargazer-starfield/tools/prepare-reader-art.py`，需要 Python 与 Pillow。生产资源已放入主题 `source/images/reader/`，常规构建不需要执行转换工具。
- 标题、日期、正文、图片和文章关联仍是真实内容；关闭控件复用既有退出 PNG。底栏固定在阅读区底部，正文可独立滚动。
- 进度按从开头滚到正文末尾所需的距离计算；长文初始 0%，中段 50%，末尾 100%。短文全文可见即 100%。关联区不计入路程，图片／字体／播放器展开及窗口变化会重新计算。读后关联与未读星标题状态沿用。
