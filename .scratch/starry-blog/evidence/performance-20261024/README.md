## 实施内容

- 只准备对应界面的图片，复用正在进行的解码。房间先绘制，天空与下一场景家具随后并行准备。选星、阅读、检索按意图准备；点击穿窗后利用原有镜头预备正文和检索装饰，不加入首页初始下载，不提前请求手记照片。当前点击的内容优先，已提高的请求优先级不会被随后整页预备降回去。
- 文章／归档直达不再预备被阅读层遮住的观测面板；关闭后需要展示时才补齐。可选图像失败不会阻止阅读，前台等候有上限。首页主模块或必要资源持续卡住时，15 秒后显示已有静态星空与文章入口；迟到的启动结果不会覆盖回退。
- UI 字体为原字形的 401 码位子集，1,236,064 → 28,512 字节；完整 15,288 码位按 215 个字符范围块提供，标题只取所需部分。逐字验证轮廓、字宽和行高，保留原字体与 OFL。完整块总量增加，依靠按需请求减少实际下载，没有声称所有字体文件总量减少。
- ESM 与样式合并压缩，保留原相对目录和 `import.meta.url`，地址带实际内容版本；独立手记只加载自身样式。正常构建不需要 Python 或图像／字体处理工具。
- 房间、天空、检索和正文采用同尺寸最高质量 WebP 显示缓存，原图继续发布；不是无损。房间／天空平均通道误差约 0.92／0.74，界面有损缓存的可见平均通道误差均低于 1，透明度保持相同。
- 观测及科技小字 52 张素材无损转换，590,772 → 323,440 字节；Logo、几何图、人物与检索框保留原尺寸及像素。检索框／背景均无损，沿用既有放大镜悬停时静止蓝底的保证。星盘 384px 缓存仅按显示尺寸选择，高像素密度会取原图；原 PNG／WebP 均保留。
- 图片原文件或缓存改变、清单缺失／损坏时自动回到当前原图，版本同时覆盖来源与显示缓存。内容哈希命名的根路径字体块配置长期缓存；其他内容和备用主题保持重新验证。配置依据 Netlify 官方 [缓存说明](https://docs.netlify.com/build/caching/caching-overview/)；本轮未验证实际线上响应头。

维护脚本、依赖及 `--force` 的使用见[操作指南](../../../../docs/operations/starfield-blog.md#首屏性能与素材维护)。图像明细见 `scene-art-summary.json`、`interface-art-summary.json`；字体验证见 `font-summary.json`。

## 最终取舍与边界

剩余主要开销是既定整幅房间／天空、云层、原尺寸 Logo／几何图，以及实际进入后的阅读／检索画面。没有为了更小数字继续降低画质、删除镜头或改变主构图；几何图渲染依赖原生坐标。更激进的分段 CSS、更多预加载及无限等待装饰会增加闪烁、无效下载或阻塞阅读，因此未采用。没有加入第三方遥测、Service Worker 或新的线上服务。

这是本机浏览器和触屏／网络模拟，不是真机、线上 CDN 或第三方音乐可用性证明。实际应用浏览器中的旧文章音乐接口仍可能报音频错误，阅读和关闭保持可用；未替换作者音源。旧 Kira 只做回归，不宣称其本轮提速。

磁盘不足造成的一次字体构建失败、以及一次与生产构建重叠的文章计时，分别标为 `invalid-font-build-startup-summary.json`、`invalid-direct-concurrent-build-summary.json`，未计入结论。仅清理了本次可重建的临时处理目录与一份确认未使用的浏览器测试缓存；保留用户内容、原画、现用浏览器和冻结基线。旧坐标式点击脚本已适配当前窗口裁切，在真实可点击区域检查，没有用强制点击掩盖命中错误。
