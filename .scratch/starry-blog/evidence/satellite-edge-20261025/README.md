# 卫星高度与边缘遮挡

作者反馈卫星位置偏低，靠近边缘提前整枚消失显得像贴图。本轮保持原图、水平位置和友链面板，抬高虚拟穹顶中的卫星位置。移除原先要求“整枚处于安全边距内”的提前剔除，交由星空容器自然裁切，整个物件离开视口后才隐藏链接和点击区域；没有添加边缘淡出或吸附。

122 项检查通过，预览及正式双主题构建成功。新增回归检查覆盖较高的初始桌面／手机位置，以及四个边缘都允许保留部分可见物件。浏览器检查了抬高后的实际位置、右侧部分遮挡仍可见、点击可见部分打开友链、完全移出后隐藏及转回后的恢复；数据见 `browser-summary.json`。`partial-edge.jpg` 展示自然裁切，`scene.jpg` 为恢复后的初始视野。

原图未修改；当前工作区其他文章和友链改动保留。本地实现，未提交或部署。
