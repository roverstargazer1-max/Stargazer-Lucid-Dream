# 13：触屏、键盘与放大后的完整浏览

Draft: pending-confirmation

本文件是待确认拆分草案，尚未发布为实施工单。

**What to build:** 手机与键盘访客能探索、读文、操作日期与旧内容层并返回，横竖屏和文字放大后核心控件仍可达。

**Blocked by:** [08：星历盘与旧标签、分类、分页入口](08-archives-and-legacy-collections.md)；[09：友链信号与旧关于内容承接](09-friends-and-legacy-about.md)。

**依赖理由：** 08 与 09 提供所有范围内集合和内容层，才能验收整站输入隔离、阅读与返回，而非仅检查文章页。

## Acceptance criteria

- [ ] 单指拖动、双指张合、点星两步阅读及返回完成核心流程，拖动不误触空白取消或内容打开。
- [ ] 正文、集合、归档、友链及旧关于内容层的滚动/触摸不驱动天空镜头，关闭后恢复相应状态。
- [ ] 桌面/手机横竖屏、紧凑高度、长短文中简介、阅读动作和按需方位图可达，保留 V20 的构图与合理热区。
- [ ] 键盘可操作入口、选星、阅读及关闭，焦点返回有实际验证；正文不因镜头层抢操作而无法阅读。
- [ ] 文字放大与浏览器原生页面缩放分别验证，核心操作及正文可达，不将 CSS 放大当作原生缩放证据。
- [ ] 系统减少动态偏好使用轻过渡，简介当次重复呈现标记不混同正文已读；具体性能装饰降级由 14 完成。
- [ ] 记录真实触屏、系统安全区、字体回退和方向变化的设备/浏览器证据；无法实测的项目明确未验证，不声称真机通过。

## 演示与测试

- 完成演示：用手机或可用触屏设备完成探索、读文、集合返回，再用键盘和放大页面完成同一阅读路径。
- 验证边界：整站浏览器/触屏外部操作和可读性对照，继承原型视口证据而补齐其验证限制。
- 验收记录应说明实际操作、环境、结果及证据；未验证设备或平台能力不标记通过。
