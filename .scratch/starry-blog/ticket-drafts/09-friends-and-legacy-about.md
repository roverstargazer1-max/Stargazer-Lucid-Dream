# 09：友链信号与旧关于内容承接

Draft: pending-confirmation

本文件是待确认拆分草案，尚未发布为实施工单。

**What to build:** 访客能从友链信号了解朋友并主动访问外站，旧关于链接仍显示原内容与歌单，而新首页没有作者介绍入口。

**Blocked by:** [05：现有正文、图片与音乐完整阅读](05-real-content-media-compatibility.md)；[07：双模式探索、移动中断与历史返回](07-modes-history-interruption.md)。

**依赖理由：** 05 已验证媒体与原内容，07 提供内容层和历史返回；旧关于播放器及友链外链才能完整承接。

## Acceptance criteria

- [ ] 把现有有效朋友信息用于信号内容，说明、名字与真实外站入口对应，不把占位社交值当真实数据。
- [ ] 只在主动选择网站后打开新标签页，保留当前星空与选中状态；桌面反馈和手机两步触碰按已确认规则呈现。
- [ ] 旧关于地址直接打开和刷新时显示原内容的轻量兼容层，歌单按 05 的主动播放与失败可读规则处理。
- [ ] 关闭或浏览器返回恢复相应星空状态，内容层的触摸/滚动不驱动背景镜头。
- [ ] 首版不整理新作者介绍、不新增首页介绍按钮或书桌介绍跳转，不把旧关于内容迁成新的手记功能。
- [ ] 旧友链/关于地址不会套回整套旧 Kira 布局，正常首页没有新增常驻文字菜单；原页文件、歌单和个人素材保留。

## 演示与测试

- 完成演示：从信号打开朋友介绍再主动访问外站，并用旧关于链接访问原歌单后返回星空。
- 验证边界：真实旧页路由、媒体失败、外链主动触发与内容层历史，不新增未确认的作者文案。
- 验收记录应说明实际操作、环境、结果及证据；未验证设备或平台能力不标记通过。
