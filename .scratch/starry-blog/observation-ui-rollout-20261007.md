本次明确反馈取代原观测注记中的可见标题、日期行及关联文字列表；其余既有决定和历史待复核状态保留。正文中的文章标题、作者关联理由及跳转继续使用原阅读窗口。

## 实现

| 作者要求 | 实际行为 |
| --- | --- |
| 23、24、25 代表年份，发布年居中 | 根据文章索引的完整发布年生成前后两年；中央箭头内显示两位发布年和 YE，不使用写死的年份整图 |
| 数字、字母使用 assets 的对应字体 | 直接引用提供的逐字 SVG 字体轮廓，构建输出与源文件逐字节相同；READ、STARLINK、OBS/ID 使用提供的原图；没有重画字形 |
| 月日随发布时间变化 | 显示 `MM.DD`，保留零填充；使用索引已按博客时区格式化的日期，不转成访客时区 |
| READ 进入详细文章 | 复用现有加载和阅读链路；移动中禁用，到位后可点击，也可再次点选同星阅读 |
| 右下几何图形自转、跳动 | 原透明几何素材每 13 秒转一圈、每 4.8 秒轻跳；完整动效模式自动循环，轻过渡静止 |
| 标题只在星旁、未读白已读灰 | 星空中只有文章星旁有可见标题；白色 `#fff`，已读灰色 `#929bbb`。面板标题仅保留屏幕阅读器标签，不显示在画面上 |

沿用已确认的当次访问阅读状态：正文布局完成后短文完整可见，或长文到达文末，标记为已读。未读到末尾关闭仍是白色；刷新后重新开始当次访问，不增加跨次访问记忆。

原资源完整保留。新增构建生成器发布 8 张透明美术图和 36 个数字／大写字体轮廓，兼容 Hexo 的站点根路径。面板按宽屏、手机竖屏、低矮横屏排布，READ 和关闭按钮至少为 44px 热区。底部提示避让几何图形。继续保留窗边入口、穹顶移动、关联／时间模式、星图、正文开合与原链接直达。

## 验证

- 预览构建、星空版生产构建通过。
- 22 项自动测试通过，包括全部真实文章年月日、跨年／闰日／世纪边界、提供的字形及美术资源原样发布，以及既有正文、关系、导航、静态输出与阅读动效测试。
- 浏览器实际核对 2025-10-20：23–27、25 居中、10.20；2026-07-05：24–28、26 居中、07.05；2026-07-17：24–28、26 居中、07.17。
- 选星更新日期，切换关联／时间模式保持同一文章及年月日；移动结束后 READ 打开匹配的正文地址，关闭恢复原星位。
- 手机阅读长文到末尾，再回星空，已读标题为 `rgb(146, 155, 187)`，其他未读标题为 `rgb(255, 255, 255)`；另验证仅打开长文后返回仍保持未读。
- 桌面完整动效模式的旋转角度和跳动位移在不同观测时变化；轻过渡模式动画为 `none`。
- 实际 CSS 视口约 1662 × 1056/1091、342 × 740、740 × 342，无横向溢出，素材完整加载，WebGL 正常；最终浏览器错误日志为空。浏览器容器与系统缩放使实际 CSS 视口不同于申请尺寸，以上记录实际读数。
- 未进行真机触摸或线上部署，本次截图用于本地视觉验收。
