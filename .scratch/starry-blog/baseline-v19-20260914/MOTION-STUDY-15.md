# V15 · 环星书卷

2026-09-12。按作者新反馈，实现广角环视、停稳后星光亮起，以及右侧书卷与延长的白色文字遮块。延续深蓝厚涂天空、暖月、云层、衬线文字和 V14 正文开合。仅迭代本地 mock 原型，主设计 R1–R6 仍待整体复核。

## 入场

| 阶段 | 时长 | 画面 |
| --- | --- | --- |
| 穿窗 | 2.1 秒 | 延续窗边推进，进入较宽视野 |
| 环视 | 16 秒 | 连续水平转过 360°，中段稍抬头，最后缓慢回落；远处文章星缩小、减亮、轻微失焦 |
| 停稳 | 0.9 秒 | 镜头完全停止，星光继续保持朦胧 |
| 星光亮起 | 3.2 秒 | 镜头位置、方向、焦距保持不变，星光渐亮、恢复清晰 |

环视使用较长的匀速段和柔和起停，避免普通缓动在中段突然加速。广角缩放从 0.50 缓慢收至最终 0.72；亮起阶段不再移动。整个引导期间收起标题、路径、导航和工具，只保留「开始探索」。按钮与 Escape 均可直接进入最终探索视角；世界恢复交互。轻过渡模式直接进入探索。

## 右侧简介

从点星起计时，完整简介动画 5.6 秒：

- 0–1.5 秒：书卷从右侧抽入，上下卷边从中央向两端舒展。白色遮块随书卷出现，覆盖日期、分类、标题和每行引言。
- 1.5–3.2 秒：书卷已完全展开，所有白块完整停留，最长行和换行后的短行都保留实际宽度；停顿末尾，封线开始消退。
- 3.2–5.6 秒：斜向细封线退去，遮块逐行收去，模糊字迹慢慢清晰；阅读入口最后显露。

文字组之间有很轻的错峰，整体仍在 5.6 秒内完成。点星镜头继续用 1.46 秒，因此到位不会提前清掉白块。保持两次点星阅读规则；用户主动再次激活已停靠的星，可提前进入正文。

书卷保留夜蓝色，与天空和暖纸正文衔接。白块按真实 DOM 行框生成，内部有细微方块分节；文字本身不拆字，装饰层带 `aria-hidden`，动画期间简介标记 `aria-busy`。文字模糊与白块分层，停顿期间白块保持实心清晰。

手机书卷从右侧进入后位于下半屏，限制高度，为星点和操控保留空间；内容过长时可滚动。改选、取消、返回和手动转向会清理旧时间轴及遮块。窗口变化时按原起始时间重测行框。轻过渡模式仅短淡入，无卷边位移、旋转或遮块。

## 实现

- `motion.js`：`PANORAMA` / `panoramaFrame()` 定义环视与亮起；`PREVIEW` 定义简介展开、停顿、显影。与 Canvas 共用 RAF 时间戳，各自保留完整时长。
- `app.js`：串接穿窗、环视、星光恢复和探索；环视中阻止误操作；支持跳过；相机到位后的手动中断也会清理简介动画。
- `painted.js` 按清晰度调节背景星亮度；`app.js` 绘制文章星时配合缩小、减亮与轻微模糊，环境绘画保持清晰。
- `motion.css`：右侧卷轴、银色卷边、白色逐行遮块与窄屏布局。
- `style.css`：收窄旧日期样式的后代选择器，避免误隐藏新增的文字和遮块层。

参考来源与 V14 的设计映射见 [MOTION-STUDY-14.md](MOTION-STUDY-14.md)。本次没有增加动画依赖或引入参考项目的素材。

## 验证

在内嵌 Chromium 的桌面约 1697×1116、窄屏约 342×740 CSS px 内容区操作实际页面：

- 完整穿窗和环视能自然完成，环视期间标题与路径隐藏，最终回到探索状态。点击「开始探索」与 Escape 都能结束环视，移除世界的 `inert`。
- 桌面完整展开的白块保持不透明、没有缩小；日期、标题和引言显影结束后装饰层全部移除。
- 窄屏引言换成两行，两行均有完整白块；日期遮块正常显示。未读文章简介完整可见，无内部滚动、无横向溢出，星点点击区域与书卷保持间距。
- 移动中重复激活同星仍保持 `moving`，不会打开正文；快速由 `night` 改选 `answer` 后，内容与遮块属于新文章。
- 镜头已经停靠、白块仍在停顿时按方向键，装饰层清理为 0，进入 `selected`，阅读按钮禁用，需重新靠近。
- 白块停顿时从桌面切到窄屏，重测换行后仍继续原来的显影进度，未重新播放展开；滚动条使用细线样式。
- 桌面和窄屏正文打开、关闭正常，返回原星与原相机；窄屏长文初始阅读进度 48%，没有提前标记已读。
- 轻过渡省略环视，简介遮块为 0，卷边位移为 0。
- 时间轴行为断言通过：完整且单调的 360° 环视，星光亮起期间相机三项参数固定，白块完整停顿介于 1–2 秒，显影至少 2 秒。
- JS 语法检查、现有 80 组穹顶几何检查通过。未做 Safari、手机真机多指手势或帧率基准测试。
