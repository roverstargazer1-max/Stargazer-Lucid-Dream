# V18 · 轻快显影与反向归窗

根据作者四项反馈调整，继续使用 V17 的同一实时星空与房间前景。R1–R6 仍待整体复核。

## 调整

- 环视仍为 7.8 秒。结束后的停稳从 0.9 秒缩至 0.3 秒，星光渐亮从 3.2 秒缩至约 1.07 秒；这段可感知的等待从 4.1 秒缩至约 1.37 秒，减少约三分之二。完整入场约 9.17 秒。
- 简介的白块后显影从 1.6 秒缩至 0.8 秒；展开 1.5 秒与完整白块停顿 1.1 秒保留，合计 3.4 秒。
- 删除简介斜向封线对应的 SVG、路径动画与样式；右侧抽入、上下展开、白色遮块与文字清晰化继续使用。
- 左上角标志与回窗边按钮共用反向过渡，完整动画约 2.6 秒，轻过渡为 220 ms。

## 反向过渡

返回时先记录当前实际相机，再停止点星推进、清除简介和遮块。房间前景沿穿窗时同一组关键帧反向播放，天空相机从当前位置连续退回房间；朝向采用最短转向，不倒放环视整圈。返回的第一帧与当前相机一致，最后一帧与窗边相机一致。

期间房间和世界都隔离交互，完成后仅恢复房间入口及手记；返回中重复操作不会叠加动画。窗口尺寸变化时按原进度重建前景时间轴，使用对应横版或竖版构图。

## 验证

- 时间轴断言：环视后等待约为原来的三分之一，显影为原来的一半；多种水平角与桌面／窄屏初始焦距下，返回起点匹配当前相机、终点匹配房间、转向不超过半圈，参数始终有限且焦距为正。
- 桌面浏览器：自然完成入场；简介白块停顿仍完整不透明，简介 SVG 数量为 0；文字最终清晰显示。
- 从选中星位点击左上标志，返回初始相机仍为原来的 `-189, 450, 756`，随后连续退至 `-180, -50, -420`；窗框和人物逐步回到画面，没有先跳到入口相机。
- 窄屏 342×740 CSS px：点星仍在推进时立即返回，遮块清理为 0、原推进停止；约 2.6 秒后回到竖版房间，入口恢复可用，天空继续保持交互隔离。
- 轻过渡可双向往返，结束后没有侧倾样式或遮块残留；完整动效模式已恢复。
- JS 语法与差异空白检查通过，浏览器控制台无错误。
