# 星空配色、低空景观与互动云：已批准方案

日期：2026-09-10。
状态：作者已明确批准 A＋B＋C 一起实施；本地 V13 原型按此执行，视觉效果待体验反馈。
范围：当前厚涂星空本地原型。主设计 R1–R6 继续保持待整体复核。

## 现象与原因

作者截图中，广角天顶中央偏深靛蓝，四周低空偏亮、偏饱和的钴蓝，形成明显色环。当前天顶使用独立底色，低空使用原厚涂素材，扩大视野后同时看到两者，差异更加突出。

第二张截图下方已是地平线以下的视野。目前这部分只有近黑底色，而且贴图底边在地平线附近出现纵向拉伸。单独添加几颗星不能解决下半部没有空间层次的问题，也会让地平线上下的含义混乱。

云朵互动可行，但目前多数云属于同一张背景素材。要让少量云独立响应，需要单独的云层及命中范围，并与现有转向、点星和云遮光一致。

## 推荐决定 A：统一深蓝色调

- 四周低空向天顶的靛蓝靠拢，降低饱和度和亮度，保留低空略亮的空气层次。
- 第一轮试调低空背景亮度约降低 15–25%，云亮面约降低 10–15%；仅为视觉起点，以实际截图定稿。
- 延长天顶和低空的颜色过渡，避免整圈亮边或明显分区。云仍保留厚涂亮暗块面。
- 不添加固定在屏幕边缘的暗角。所有颜色跟随天空方位和高度，转动时不会像隔着一层滤镜。
- 文章星维持可辨识度，银河保持隐约，不用提亮中央来追平四周。

## 推荐决定 B：低空雾海、远山与极少暖灯

推荐结构：低空厚涂云 → 蓝灰薄雾 → 两层低对比远山 → 深靛蓝的雾海／山谷暗部。

- 地平线附近增加少量柔软云雾与远山轮廓，让深色下半部有层次、距离与着落。
- 下方保留有蓝色和微弱笔触的暗部，不再是一整片均匀近黑。
- 只在某个方位放两三点暖灯，弱于文章星，贴近山脚或极简聚落轮廓，不漂浮、不闪烁、不响应点击。
- 山形与灯点的位置固定，可作为认方向的地标。远景随观察方向投影，抬头时自然退出画面，不固定贴在屏幕底部。
- 修掉地平线附近的纵向拉伸，低空填充覆盖广角所能看到的地平线以下区域；不增加可探索的下半球文章空间。
- 保留当前仰望、回正及拖动范围；本轮不引入自动抬头、镜头回弹或缩小时改变朝向。

备选：

| 方案 | 效果与取舍 |
| --- | --- |
| 只有低空雾海 | 最轻盈，最接近纯天空；固定方向地标较弱。 |
| 雾海＋远山＋少量暖灯（推荐） | 给下半部空间层次和稳定方向参照，也延续窗边入口的生活感。 |
| 湖面／海面与倒影 | 可填满大面积下方，但倒影容易与文章星混淆，需额外控制动态和亮度，暂不推荐本轮。 |
| 近景屋顶或完整城市 | 生活感强，但会明显改变窗外自由星空的构图，占用更多画面，暂缓。 |

## 推荐决定 C：3 朵可轻触的云

- 首轮仅 3 朵，散布在低空至中低空，避免集中挡住文章。
- 桌面指针靠近时，云边极轻微提亮；短点击后云体轻轻散开／偏移，露出已有背景碎星，约 6–8 秒恢复。手机短点按触发同一反馈。
- 不弹文字、不跳转、不计分、不播放声音；暂不绑定归档、友链或文章解锁。
- 拖动超过现有手势阈值仍然只转动天空；拖动结束不触发云彩蛋。双指缩放也不触发。
- 文章星和导航控件命中优先。互动云只在可见云体内响应，透明边缘不形成大块拦截区域。
- 云的绘制、遮光和命中一起更新；移动后的空位不能留下原来的遮罩，云后的星光仍柔和衰减。
- 重复点击不叠加动画或粒子。阅读时暂停，系统减少动态偏好下只做短暂透明度／明暗变化。
- 背景云不同时全面运动，不增加常驻的大幅漂浮，保持安静的整体节奏。

如果需要后续趣味，优先考虑某朵云偶尔露出短暂的月光轮廓或淡流星；首轮不叠加多种彩蛋，先判断轻触云是否自然。

## 实施顺序与检查

1. 先完成配色与地平线连续过渡，检查默认、天顶广角、最低朝向和四周转向。
2. 加入低空景观，检查桌面横屏、手机竖屏及宽窄缩放：无黑色空洞、无贴图拉伸、无接缝，天顶不出现固定前景。
3. 再接入 3 朵独立互动云，检查短点／拖动／双指区分，星与云重叠时的命中优先级，以及云遮光同步。
4. 验证点星、阅读返回、仰望、回正、小星图与快速移动隐线；提交实际截图供作者复核。

批准范围可以是 A＋B＋C，也可以先做 A＋B。批准本方案不等于批准主设计 R1–R6，也不涉及正式发布。
