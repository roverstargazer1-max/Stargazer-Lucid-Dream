# 第一轮：静态明暗与星体质感

日期：2026-09-09。原型分支：`codex/prototype-starfield`。两版均待作者比较，尚未选定最终美术。

这轮回答：在既定的 C 阅读布局、小比例二次元屋顶和稀疏文章空间下，哪种暗部与光色更适合这个个人世界？先比较静态画面，再决定动画。

## 两版入口

- [01 · 墨蓝冷夜](http://127.0.0.1:4173/pages/starfield-prototype/?variant=C&roof=anime&art=ink)：冷黑天空、灰蓝建筑、偏中性的暖灯；降低原来的蓝金对比。
- [02 · 烟褐旧梦](http://127.0.0.1:4173/pages/starfield-prototype/?variant=C&roof=anime&art=umber)：炭黑与灰褐暗部、略暖的星光与灯光，比较更旧、更低饱和的气氛。

底部配色选择保留当前镜头、选中文章及阅读状态。这里特意只改变静态配色与光色，保持构图以便对比。既有布局和屋顶风格选择藏在“调试”中。

## 已实现

- 复用二次元屋顶素材，通过合成时的低饱和调色融入暗部，没有重新生成天空或建筑。
- 天空采用不均匀星密度、暗带、细弱的扁平云气与局部地平线灰雾；去掉全屏均匀颗粒和文章周围的规则避让暗圈。
- 文章星改为小光核与渐散射。按文章 ID 固定生成大小、亮度、散射宽度和类型差异；主体为清冷针点及暖白柔光，少量双星与短星芒。
- “星体样本”展示四类星体的原始大小与 5 倍细节，下方展示不同 ID 的稳定差异。窄屏改为两列；画布按 CSS 尺寸与像素比绘制，避免整张缩小影响尺寸判断。
- 原型比较工具单独收纳，默认只显示配色、样本和调试入口。

## 本轮边界

“静态”指星体外观和天空没有加入新的时间动画，已有探索镜头与点击彩蛋仍可操作。没有加入大气闪烁、随机色温偏移、鼠标微视差，也没有重做 Logo、字体或正文排版。星体是审美化的光点绘制，不是天文光学仿真。

样本里的四类不是强制文章分类。双星和短星芒是当前视觉实验，不代表作者已同意赋予它们额外含义。

下一轮应根据作者对两版明暗、屋顶融合度及星体尺寸的反馈收敛，再加入不同步、幅度克制的动态。主设计文档中待整体复核的规则保持原状态。
