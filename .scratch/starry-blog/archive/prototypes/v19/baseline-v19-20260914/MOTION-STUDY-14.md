# V14 · 星光牵出书页

2026-09-11。按作者要求实现参考 RhineLabUI 的连贯动效，延续当前 V13 深蓝厚涂场景与 C「漂浮书页」。这是原型中的动效迭代，不改变主设计文档 R1–R6 待整体复核的状态，不代表正式主题已完成或发布。

## 从参考中提取什么

参考：[RhineLabUI](https://github.com/LBEILC/RhineLabUI)，以及作者提供的 10 秒本地录屏。视频约 4.5 秒开始选中文档、5–8 秒抽出与展开，约 8.5–9.5 秒斜向封线消退、正文信息逐行清晰。观察重点是主体运动与文字显露之间的因果。

源码中的 [motion.ts](https://github.com/LBEILC/RhineLabUI/blob/main/src/motion.ts) 使用平滑的运动阶段；[document-decryption.ts](https://github.com/LBEILC/RhineLabUI/blob/main/src/document-decryption.ts) 根据模型的清晰度信号开始移除正文遮挡。借鉴的是共同时间轴、先后层次、空间来源和返回动作的连续性。本次没有引入其模型、字体、音效或品牌素材，也没有新增动画依赖。

| 参考动作 | 星空中的表达 |
| --- | --- |
| 档案响应选择 | 两段细光弧向所选星光收束 |
| 档案从阵列抽出 | 镜头先转向，位移与焦距随后跟进 |
| 周边信息等待主体 | 引言在推进后半段由中间铺开，文字随之显影 |
| 实物打开、封线消失 | 星点牵出狭长纸页，逐渐摊开，银灰斜线向两端退去 |
| 黑块显露数据 | 与真实文字行宽一致的雾蓝遮罩退去，字迹由模糊到清晰 |
| 物件归位 | 同一段书页时间轴反向播放，回到原星点 |

保持已有深蓝天空、暖月亮、云、衬线标题与暖色纸面。引言去掉圆角卡片边框，保留一条细的顶部光线与大面积留白；连接线在停靠后减淡，不加入故障字符、扫描仪表或机械音效。

## 实现与节奏

- `motion.js` 管理镜头阶段、可取消的 DOM 时间轴、真实文字行遮罩及书页开合。`motion.css` 是独立的视觉覆盖层。
- `app.js` 的 Canvas RAF 同时驱动镜头、引言进度和书页进度。点星的转向先于位移与镜头放大，端点速度归零。
- 窗边进场使用同一进度驱动房间退出、天空亮度与镜头位移。完整进场 2100ms；点星 1460ms；书页展开及显影 1460ms；完整收回 820ms。
- 书页先在所选星的投影位置形成狭长纸片，展开后文字逐行清晰。标题、日期、引言和首屏正文使用真实 DOM 行框，不拆字，不替换原始文本。装饰遮罩带 `aria-hidden`，动画结束移除。
- `opening` 与 `closing` 期间保持模态隔离；正文完成显影之后才进入 `reading` 并检查是否到达文末。关闭键与 Escape 在过渡中可用。
- 移动中重复点同星不排队打开；改选会清理旧时间轴，从当前镜头开始；手动中断会移除未完成遮罩。关闭后再执行关联跳转，避免前后两篇文章的状态互相覆盖。
- 窗边和调试栏共用轻过渡状态。`motion=full` 用于本次完整动效体验，`motion=soft` 使用 160–220ms 的短过渡，省略纸片旋转、遮罩、光弧和模糊；无显式选择时采用系统减少动态偏好。
- 底层 Web Animations 用暂停的 `Animation.currentTime` 同步至 RAF，取消时处理 `finished` 的拒绝。相关 API 经 Context7 / MDN 核对：[Animation.cancel](https://developer.mozilla.org/en-US/docs/Web/API/Animation/cancel)。

## 验证

在 Codex 内嵌 Chromium 中操作实际页面，桌面内容区约 1697×1116 CSS px；窄屏内容区约 342×740 CSS px（预览尺寸受主机显示缩放影响）。

- 桌面进入窗外、点星、引言显影、再次点星展开与合上完成；返回后仍是 `night`，相机 `(-189,450,756)` 与方向 `(-0.24,0.45)` 和打开前一致。
- 移动中连续两次键盘激活 `night`，阶段保持 `moving`，正文未打开，4 个引言遮罩仍在；结束后可读、遮罩清除。
- 从 `night` 立即改选 `answer`，引言与选中身份变成 `answer`，正文未打开，旧遮罩清理并建立新遮罩。
- 切换至时间模式后用方向键打断，保留 `answer` 身份，阶段为 `selected`，进入阅读按钮禁用，遮罩清理为 0。
- 观察完整书页的抽出、展开与文字显影中间帧；`opening` 时保留文字遮罩且未新增已读标记，结束后遮罩数为 0。完整可见正文在显影后触发已读。
- 展开途中按 Escape，状态立即转为 `closing`，最终模态关闭、遮罩为 0、焦点返回星点。
- 窄屏引言与正文无横向溢出；阅读层填满可用视口，正文可滚动，返回按钮保留。
- 轻过渡模式下书页没有变换或文字模糊，遮罩数为 0；窄屏长文展开后为 48% 且未读，滚动至文末后为 100% 并显露关联，镜头坐标未变。
- `node --check` 检查改动的 JS，现有 `dome-check.mjs` 的 80 组投影、360° 连续性、目标可达性与稳定坐标检查通过。

仍需作者亲自确认节奏与视觉感受；未做手机真机多指手势、Safari 或帧率基准测试。文章仍为 16 篇 mock；本地预览服务的限制与正式 Hexo 发布隔离保持原样。
