# V17 · 同一片星空，连续穿窗

2026-09-12，根据作者关于开场力度、窗内外连续性与显影速度的反馈调整。沿用当前厚涂画风、无框引言和正文阅读；R1–R6 仍待整体复核。

## 画面与节奏

- 窗外直接显示探索阶段的同一个实时星空画布。横版、竖版各用一份 SVG 遮罩保留原插画的房间、窗框、人物、椅子与桌面，移除窗格中的静态天空；原始 PNG 不改动。
- 两份遮罩预先加载，实时天空与遮罩就绪后启用透窗合成。窗边状态隐藏文章标签和导航线，世界交互仍隔离。
- 穿窗开始即转向，近处前景侧移、倾斜、放大并退出；远处月亮、云与星点使用连续的相机位移、朝向与焦距。天空不再单独淡入，房间退场不重置相机。
- 穿窗 1.9 秒；环视从 12 秒缩为 7.8 秒，短加速后维持约 51.3°/秒。穿窗结束时已转过约 77.4°，继续完成一整圈。之后仍停稳 0.9 秒，再用 3.2 秒让星点清晰明亮。总长约 11.9 秒。
- 相机在穿窗中途轻微侧倾，结束前回正。天空同步留出旋转所需的覆盖范围，避免屏幕角落露出空白。手机初始视角更宽，让月亮完整留在窗内。
- 引言展开仍为 1.5 秒，白块完整停顿仍为 1.1 秒；逐行显影从约 2.4 秒缩至 1.6 秒，总长从 5 秒缩至 4.2 秒。斜向封线仍在白块停顿结束附近退去。
- 入口容器改为 `overflow: clip`，避免焦点自动滚动令大幅前景突然横移；键盘入口提示保留轻微下划线。

## 实现范围

使用原插画的前景分层与同一实时穹顶构成空间连续感，房间本身仍是插画平面，并未新增完整室内三维模型。`motion.js` 计算共同时间轴；`painted.js` 驱动近景退场；`app.js` 延续天空相机并处理交互交接。新增两份代码原生 SVG 遮罩，无新增运行依赖。

CSS 遮罩依据 [MDN mask-image](https://developer.mozilla.org/en-US/docs/Web/CSS/mask-image) 的 alpha 透明度规则实现，通过 Context7 核对。

## 验证

- 数值断言：穿窗交界两侧的位置、俯仰、焦距、侧倾和水平角连续，角速度不归零；环视完成 360°；停稳后才恢复清晰度；桌面、窄屏和超宽屏的旋转覆盖范围足够。
- 桌面 1697×1116 CSS px：查看穿窗初段、中段和退场画面，月亮连续穿过窗框后进入开放天空；入口焦点前后前景位置差约 0.002 px，容器无横向滚动。
- 窄屏 342×740 CSS px：竖版前景与遮罩匹配、月亮完整可见，倾斜与退场没有露出空白边角；引言两行均有完整不透明白块，无横向溢出。
- 停顿阶段白块 opacity 为 1、文字 blur 为 3 px；显影结束后遮块与临时文字包裹均清除。
- 环视自然完成、Escape 跳过、返回窗边后再次进入、220 ms 轻过渡均可用。
- 阅读开合后返回同一文章与原相机，遮块无残留，浏览器控制台无错误。JS 语法、SVG XML 解析与差异空白检查通过。
