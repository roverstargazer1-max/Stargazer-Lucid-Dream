# V16 · 连续穿窗与无框显影

2026-09-12，根据作者截图及三项反馈调整。继续使用当前星空和文章原型；R1–R6 待整体复核的状态保持不变。

## 视觉与节奏

- 删除上下卷柄对应的 DOM、动画与样式，同时去掉直边框、矩形底色和盒状阴影。简介背后只保留边缘自然渐隐的夜色，正文仍可辨认。
- 保持右侧抽入、上下展开、白块遮挡、斜向封线消退和文字由模糊变清晰。封线使用更轻的银蓝细线。
- 展开仍为 1.5 秒，完整白块停顿从 1.7 秒减至 1.1 秒，随后约 2.4 秒完成逐行显影，总长 5 秒。
- 环视一圈从 16 秒缩为 12 秒。穿窗开始 0.7 秒后即开始转向，与 2.1 秒的穿窗阶段重叠 1.4 秒；穿窗结束时角速度不会重新从零起步。
- 环视之后的 0.9 秒停稳与 3.2 秒星光亮起保留。完整入场从约 22.2 秒缩至 16.8 秒。

## 实现

`motion.js` 的 `entranceFrame()` 在同一时间轴内计算前进、转向、俯仰、焦距和星光清晰度。`painted.js` 把房间动画的起始时间传给 `app.js`；房间退场仅交接交互权限，不重置镜头时间。轻过渡使用原有短淡入。

`motion.css` 使用透明容器与柔和径向底色；保留原有文字布局与窄屏换行测量。新增的渐隐层不拦截点击。

- 时间轴断言：穿窗前已转向；穿窗交界两侧的角速度连续且非零；位移连续；完整转过 360°；星光亮起时镜头保持固定；白块停留比原版缩短约三分之一。

- 窄屏约 342×740 CSS px：简介两行引言均有正确遮块，无横向溢出；天空、云与文字自然衔接。
