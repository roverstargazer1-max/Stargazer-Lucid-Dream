## Acceptance criteria

- [ ] 从已验证通用实现整理独立的完整项目工作副本，含站点骨架、准备与校准工具、选定依赖基线及配置示例。
- [ ] 使用通用示例文章、关系、朋友示例与通用桌面/手机房间插画，默认运行即可展示核心效果。
- [ ] 逐项排除个人文章、个人介绍、个人歌单/朋友数据、个人场景、旧 Kira 版本及原型 mock/调试素材；通用代码不依赖个人仓库。
- [ ] 默认素材来源、再分发条件和所用代码许可证清楚，不能把个人插画仅改名视作通用素材。
- [ ] 在空环境安装、运行、换文案和文章、校准不同图、准备并构建，真实正文回退与稳定星位仍成立。
- [ ] 配置的缺省/版本兼容、导出导入和取消表现与个人站点一致；日常操作无需编辑通用前端代码。
- [ ] 形成可检查的模板清单、基础说明与本地验收结果，公开仓库发布与从远程复制的托管验收由 17 完成。

## 演示与测试

- 完成演示：从通用项目副本在空环境安装，只改内容/配置并换一组图，生成自己的星空博客。
- 验证边界：模板作为完整公开接口，从复制工作副本到新内容构建验证，不仅检查文件已复制。
- 验收记录应说明实际操作、环境、结果及证据；未验证设备或平台能力不标记通过。
