## Description

以 mock 数据实现可操作的星空，用实际体验判断视觉、镜头推进和阅读衔接。用户本次已授权原型开发，不涉及正式博客替换或部署。

评审记录：[prototype-review.md](../prototype-review.md)。原型源代码：`themes/hexo-theme-kira/prototypes/starfield/`。

## Acceptance criteria

- [x] 一个本地命令启动，不接入真实内容或远端服务。
- [x] 三种结构方案以 URL 参数与底部工具条切换。
- [x] 实现点星推进、二次阅读、恢复视角、关联和时间模式。
- [x] 浏览器实际验证连续探索、移动期间重复激活、阅读完成与返回状态。
- [x] 验证移动端布局与指针拖动、滚轮移动。
- [ ] 在真实触屏上验证单指、双指手势手感。
- [x] 作者体验并记录第一轮视觉方案与镜头、阅读参数的取舍。
- [ ] 作者复核 V3 星空层次、文章可发现性、屋顶前景和快速推进镜头。
