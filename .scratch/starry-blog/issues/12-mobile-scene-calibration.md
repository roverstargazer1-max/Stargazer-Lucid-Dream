# 12：手机独立插画与校准配置往返

Status: ready-for-agent
State: open
Category: enhancement

2026-09-30 用户要求按全部任务顺序自主实施并逐票提交，本票据此正式发布。

**What to build:** 使用者能为手机配置独立插画和互动区域，横竖屏变化后窗口及穿窗仍对齐，桌面与手机配置可保存并再次导入。

**Blocked by:** [11：桌面插画校准、导出与穿窗预览](11-desktop-scene-calibration.md)。

**依赖理由：** 11 已实现桌面校准的工具、数据契约和正式主题消费，本票扩展成完整双画幅使用流程。

## Acceptance criteria

- [ ] 桌面与手机素材、窗口、互动区域、遮罩及镜头参考可分别设置，不要求两张图保持相同构图。
- [ ] 工具能选择并预览目标画幅，将同一组场景配置导出、再次导入后重现编辑结果。
- [ ] 手机首屏、横竖屏及紧凑高度中的实际裁剪与互动区域对齐；穿窗和返回均使用对应场景配置。
- [ ] 配置版本字段、缺省兼容和错误提示完整；桌面已校准结果不因编辑手机而改变，取消保持保存结果。
- [ ] 把一套与个人场景不同的桌面/手机素材仅通过配置接入正式站点，日常无需编辑通用前端代码。
- [ ] 导出或导入不携带原型调试设置、不新建介绍入口，保留原素材及当前已保存配置。
- [ ] 记录校准预览与实际设备表现的验证范围；视口模拟不冒充真实触屏验收。

## 演示与测试

- 完成演示：分别换桌面和手机构图，导出后重新载入，切横竖屏并验证各自往返穿窗。
- 验证边界：完整双画幅编辑/导入导出和正式预览；不对每个坐标公式写重复测试。
- 验收记录应说明实际操作、环境、结果及证据；未验证设备或平台能力不标记通过。
