# 07：双模式探索、移动中断与历史返回

Status: ready-for-human
State: open
Category: enhancement

2026-09-30 用户要求按全部任务顺序自主实施并逐票提交，本票据此正式发布。

**What to build:** 访客能在关联/时间模式间继续聚焦同文，途中改选或中断后不会误开正文，停靠返回及浏览器历史始终对应当前内容。

**Blocked by:** [06：双向文章关联与读后理由](06-bidirectional-relations.md)。

**依赖理由：** 06 提供真实多文章及采用关系，才能验证时间模式不冒充语义关系、跨模式理由与导航状态。

## Acceptance criteria

- [x] 时间模式按日期与固定身份稳定排序，补发影响时间落点但不移动关联模式旧星；时间相邻不生成语义关系，默认不展开语义线。
- [x] 有选中文章时切换模式聚焦同文，未选中时进入目标模式默认起点；已满足阅读条件的文章仍能查看采用理由。
- [x] 推进中改选更新目标，手动转向/移动中断；中断后再次点星先靠近，到位后第二次点按才阅读，不执行过期动作。
- [x] 点空白取消选中但保留镜头、收起选择提示，拖动结束不视作空白点击。
- [ ] 阅读及其他内容层的滚动、触摸与背后镜头隔离。窄屏视口下验证了滚动与镜头隔离；真实触屏输入/设备未验证。
- [x] 只在自动停靠完成后记录返回点，手动巡视不逐帧记录；换模式建立当前布局起点，不能用另一模式坐标返回。
- [x] 当次阅读标记跨模式共享；完整简介的重复呈现标记独立于正文已读标记，刷新不恢复探索历史。
- [x] 文章切换、关闭、前进后退、直达和刷新后地址与显示内容一致；无历史直达也能回对应关联星及窗边。
- [x] 另一篇文章加载失败时保留已可读内容与真实地址访问，不能把地址改成未成功显示的文章。
- [x] 将取消/改选、长短文、正常与直达两种进入方式串成浏览器验收，不以原型纯逻辑测试代替正式链路。

## 演示与测试

- 完成演示：读一篇文章后切时间模式、途中改选并手动中断，再前进后退和关闭，核对同文身份及地址。
- 验证边界：最高层浏览器状态与地址；必要时沿用取消/改选和停靠的少量行为测试先例。
- 验收记录应说明实际操作、环境、结果及证据；未验证设备或平台能力不标记通过。
