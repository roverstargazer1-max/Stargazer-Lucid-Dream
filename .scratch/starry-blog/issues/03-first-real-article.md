# 03：一篇真实文章的星空阅读闭环

Status: ready-for-agent
State: open
Category: enhancement

2026-09-30 用户要求按全部任务顺序自主实施并逐票提交，本票据此正式发布。

**What to build:** 访客能从当前窗边进入星空，选择一篇真实文章并阅读、返回；直接打开原地址或星空启动失败时，同址真实正文仍可读。

**Blocked by:** [02：旧版博客可重建与隔离预览](02-legacy-recovery-baseline.md)。

**依赖理由：** 02 提供可恢复的旧站与路由基线；本票建立后续任务复用的内容、页面及交互入口。

## Acceptance criteria

- [ ] 正式星空与旧版独立组织，保留当前 C 阅读方向、窗边厚涂风格、穿窗和现有小交互；首个验收使用真实文章，正式输出不出现 mock 文案和调试工具。
- [ ] 首篇文章有固定身份、已保存位置和真实原地址；文章索引、静态页面与星空阅读引用同一份 Hexo 内容。
- [ ] 生成正确标题、摘要、正文、规范地址及分享信息，直接打开和刷新原地址即可看到对应文章。
- [ ] 首次点星只选中、推进并显露引言；移动中重复点按不打开或排队，到位后再次点同星进入正文。
- [ ] 关闭阅读回进入前视角与选中星，直接链接进入没有前置停靠历史时仍可回对应星附近及窗边。
- [ ] 分别禁用脚本、阻断主脚本加载、模拟初始化异常和 WebGL 不可用，同址正文仍可读；只有准备成功后才切入星空。
- [ ] 保留桌面基本拖动和滚轮探索，不以静态背景替代当前共同穹顶与连续穿窗；完整多文章历史及触屏扩展分别由 07、13 验证。
- [ ] 旧版仍可按 02 的步骤构建，首篇真实链路在浏览器完成演示并记录。

## 演示与测试

- 完成演示：打开旧文章链接读文，再从窗边选星读同文、返回，最后禁用脚本读同址正文。
- 验证边界：以一篇真实文章串起生成站点和浏览器行为；对脚本/渲染失败做外部故障注入。
- 验收记录应说明实际操作、环境、结果及证据；未验证设备或平台能力不标记通过。
