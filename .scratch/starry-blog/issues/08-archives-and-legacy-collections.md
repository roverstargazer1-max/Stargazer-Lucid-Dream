## Acceptance criteria

- [x] 星历盘只提供有文章的年月，选择后进入时间模式并定位该时期起始文章，没有空日期入口。
- [x] 旧归档年月和分页路由承接原范围，旧标签/分类及其分页打开相应文章清单，不能统一退回首页掩盖缺失路径。
- [x] 清单中的每篇文章可用真实地址访问并进入同篇星空阅读，关闭或浏览器返回恢复对应集合状态。
- [x] 直接打开、刷新和前进后退均显示正确集合，中文编码和站点根路径经过实际构建验证。
- [x] 集合层的滚动不移动镜头，正常首页不新增归档/标签/分类常驻文字菜单，日期入口沿用当前场景。
- [x] 采用真实构建路由清单逐项核对，记录无实际内容的边界和现有分页范围，不凭几个示例声称全兼容。
