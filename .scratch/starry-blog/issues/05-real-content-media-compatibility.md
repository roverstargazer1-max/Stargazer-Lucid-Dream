## Acceptance criteria

- [ ] 逐篇核对实际现有内容的 Markdown、HTML、内联样式、代码块、封面和元信息，不把不新增功能解释为丢弃既有内容。
- [ ] 根路径与相对图片在原地址、星空内切文和静态阅读时正确；页内链接与中文标题锚点保持可定位。
- [ ] 明确并验证实际使用的音乐标签、文章附加 HTML 播放器及旧页音乐来源，按内容加载所需资源；未使用的旧自定义标签不扩大为首版工作。
- [ ] 音乐由主动操作播放，第三方音乐请求或播放器脚本失败不阻止正文阅读，不产生新版全站自动播放。
- [ ] 检查 Kira 全局正文过滤及重复标签注册对新主题的影响，限定适用范围或隔离构建，并验证旧版依赖继续可用。
- [ ] 记录正文内音乐与旧关于/归档独有歌单的区别；旧关于界面承接在 09 完成，不新增手记介绍或音乐场景功能。
- [ ] 用生成站点和浏览器留下每种实际格式的兼容证据，旧版仍可按基线重建。

## 演示与测试

- 完成演示：选取包含相对图片、HTML、锚点和播放器的真实内容，在正常阅读与资源失败两种条件下打开。
- 验证边界：真实格式清单对应页面检查、链接与媒体故障注入、旧版回归；不为未使用标签写镜像测试。
- 验收记录应说明实际操作、环境、结果及证据；未验证设备或平台能力不标记通过。
