# 11：桌面插画校准、导出与穿窗预览

Status: ready-for-agent
State: open
Category: enhancement

2026-09-30 用户要求按全部任务顺序自主实施并逐票提交，本票据此正式发布。

**What to build:** 使用者在本地界面载入不同构图的桌面图片，描画窗口与互动区域，导出配置后完成真实穿窗及返回，而不用改前端代码。

**Blocked by:** [10：通过配置定制内容与星空外观](10-content-and-appearance-config.md)。

**依赖理由：** 10 建立配置与通用实现边界，本票让场景校准数据从工具进入同一套正式体验。

## Acceptance criteria

- [ ] 一个清楚的本地启动方式打开校准工具，可载入桌面插画并标记窗口通透区、入口点击区、遮罩与镜头参考。
- [ ] 坐标相对于图片保存，预览能复现图片缩放/裁剪下的点击区域、窗口露出和往返过渡。
- [ ] 支持描画、修改、导入已有配置、导出版本化配置及取消；导出后由使用者明确保存，不默默覆盖素材或正式设置。
- [ ] 把导出结果用于实际正式主题，一套不同构图图片仅修改素材和配置即可完成入口、穿窗及返回。
- [ ] 损坏文件、缺少必需区域或失效素材引用有具体提示，有效原配置保持可用；取消不改变已保存结果。
- [ ] 工具只负责本地场景校准，不制作在线后台或作者介绍跳转；现有手机默认场景仍可使用。

## 演示与测试

- 完成演示：用不同桌面构图描画窗口、导出并用于博客，演示穿窗、返回和取消不覆盖。
- 验证边界：工具公开操作→导出→主题导入→浏览器预览，覆盖相对位置、取消及错误数据。
- 验收记录应说明实际操作、环境、结果及证据；未验证设备或平台能力不标记通过。
