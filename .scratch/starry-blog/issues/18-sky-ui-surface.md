# 星空界面黑雾：替代视觉试稿

Status: ready-for-human
State: open
Category: enhancement

## Description

2026-10-02 作者反馈：文章入口、右上操作和星图控制背后的黑雾让云层变脏，文章区域的雾被容器裁切，边缘有明显断层。要求再给几版方案，尚未选定替代设计。

试稿复用正式主题、真实文章和原有操作，仅改变这些界面区域的承载方式；不改正式主题或文章数据。捕获分支：`codex/prototype-sky-ui-20261002`，试稿目录 `.scratch/starry-blog/prototypes/sky-ui-20261002/`。

## Acceptance criteria

- 对比三种不同的界面承载方式，覆盖文章入口、探索控制和方位控制。
- 保留当前阅读窗口和 B 开合、点星标题显字，以及真实文章的阅读与返回。
- 可在同一个真实场景切换，附实际截图与窄屏布局检查。
- 作者选定后另行合入正式主题；当前不推送。

## Comments
