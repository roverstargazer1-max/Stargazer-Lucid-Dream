## Acceptance criteria

- [x] 导入全部现有文章并在实施开始时更新清单，不因正文中的“草稿”等措辞改变公开状态；每篇文章均能在星空选中并访问真实内容。
- [x] 固定身份独立于显示标题、文件名、日期、数组序号及缓存 ID；首次导入记录原地址，更名或改日期后保持已有身份与原链接。
- [x] 本地发布准备自动补新文章身份、分配关联模式位置并保存版本化结果；作者把结果随文章提交，日常无需手填坐标。
- [x] 重复准备、干净重建、新增有关系/无关系文章、补充远距离关系均保持已有坐标；空站点、孤立文章和拥挤布局也能发表。
- [x] 删除后恢复仍识别原文章，其他文章身份与位置不受影响；同日期与补发旧文有可重复的时间排序数据。
- [x] 引言可手填，缺省提取纯文本并排除标题、图片和播放器语法；星座名未填省略，命名不移动星位或限制写作。
- [x] 重复身份、重复地址或损坏必需数据给明确错误；可选信息缺少不阻止有效文章访问。
- [x] 托管构建只校验和消费已提交布局，缺少新文必要数据时给出本地准备提示，不依赖 CI 临时生成且未保存的坐标。

## 演示与测试

- 完成演示：新增一篇孤立文章、准备两次并重建，比较旧星位不变；再改名、补发与恢复文章验证身份。
- 验证边界：通过准备命令、保存结果和真实站点验证幂等、身份及位置稳定；不对照实现公式。
- 验收记录应说明实际操作、环境、结果及证据；未验证设备或平台能力不标记通过。
