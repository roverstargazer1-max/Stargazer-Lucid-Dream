# 人物剪影原地步行

日期：2026-10-08。首版历史记录：作者已否定本版的人体结构和走路姿势，当前实现已被[参考视频重做版](silhouette-walk-redo-20261008.md)取代。以下几何和运行检查只证明代码运行及数值约束，不能证明步态自然或人体结构正确。

作者提供 `assets/详情弹窗/详细工程文件/人物剪影.png`，要求人物走路，但留在原地。

## 实现

- 直接使用现有发布 PNG 的像素与轮廓，源图和发布副本不改。通过髋部、膝盖、脚踝和鞋底控制点变形，保留头发、侧脸、衣服和鞋子的造型。
- 人物的面板位置及髋部水平坐标固定，两腿错开半个周期，交替向前迈步、屈膝抬脚及回落。一轮双腿循环为 1.5 秒，接触期约占单腿周期的 62%；脚掌按落地、支撑和蹬离调整角度。
- 用两段腿长计算膝盖位置，抬脚时屈膝。上身轻微起伏和摆动，腰部与腿部平滑衔接。
- 使用缓存纹理与小型三角网格，空白区域不绘制；接入已有星空循环，常态最多每秒更新 30 次，设备像素比上限为 2。
- 轻过渡、低性能、系统减少动态及画布不可用时显示原静图。阅读、面板隐藏、弹层、返回窗边和页面隐藏时不运行步行。

## 验证

- Node 22.19.0、npm 10.9.3 下，26 项现有检查通过，人物 PNG 发布字节检查通过；准备步骤没有修改文章和星位。
- 新版预览和正式主题构建均通过，各生成 147 个文件。
- 桌面 1440 × 900、手机 390 × 844 和横屏 844 × 390 各取样约 3 秒，腿部出现 38～40 个不同画面。人物承载框的位置始终固定，画布位于视口内，画布边缘无可见像素裁切，控制台无运行错误。
- 上身轻摆的头部中心水平变化范围约 0.8～1.2 CSS px，未产生人物整体向前移动。几何取样覆盖整轮步行：髋部水平位移为 0，脚掌接触期的地面误差及整轮衔接误差均小于 1e-9 源图像素。见[几何检查](evidence/silhouette-walk-20261008/geometry-checks.json)。
- 浏览器本机取样中，人物单帧平均绘制约 0.36～0.8ms，最大约 2ms；三种尺寸均保持完整装饰质量。此为本机证据，不代表所有设备。
- 三种尺寸的轻过渡均显示原 PNG 并停止绘制，恢复完整动效后继续；模拟页面隐藏及打开正文后停止绘制。见[浏览器检查](evidence/silhouette-walk-20261008/checks.json)。
