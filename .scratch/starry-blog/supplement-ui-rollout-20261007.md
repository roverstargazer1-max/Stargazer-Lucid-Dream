# 观测面板补充图形替换记录

日期：2026-10-07。状态：已实现并验证。

作者指出上一版小图形不准确，并新增 `assets/详情弹窗/详细工程文件/补充图形.png`，明确允许裁切或直接使用，要求不要自行绘制 SVG。本次接续[上一版记录](observation-ui-rollout-20261007.md)。

## 素材与界面

- 从补充原图直接裁出年份箭头、菱形、径向刻度、括号、斜线方框、CALL 与下划线、H-、READ 上方折线，共 8 个 PNG。原图、裁片和[裁切坐标](../../assets/详情弹窗/详细工程文件/supplement-crops/crops.json)一起保留，裁片像素与原图对应区域一致。
- 删除此前以 CSS 拼出的这些装饰图形，使用原图裁片。数字和其余技术字母使用作者字形包中 36 个现成透明 PNG，构建输出与源文件字节一致。
- 调整 YE 在原图箭头内的尺寸，桌面和手机均保留原图比例。READ 字样仍使用原有素材，按钮正常打开对应正文。
- 五行年份以文章发布年居中，月日按文章日期变化，读后标题变灰和右下几何旋转／轻跳行为沿用上一版。历史待整体复核状态保留。

- 桌面和手机实看：没有缺失图片或横向溢出，YE 位于年份箭头内，READ 可打开对应正文。检查日期 `2025-10-20`，中心年份为 `2025`、显示 `25`，月日为 `10.20`。
- 另一篇文章 `2026-07-05` 返回星空后显示 24–28、中心 26、月日 `07.05`，所有动态字形加载原 PNG。

## 波浪纹理细调

作者反馈纹理太淡后，将波浪图层的不透明度从 `0.17` 提高至 `0.4`。原素材和排布保持，预览与正式构建通过，浏览器实看确认纹理更清楚。效果见[调整后截图](evidence/supplement-ui-20261007/waves-opacity.png)。

随后按作者要求，将波纹整体上移面板高度的 8%，位置由 `top: 65%` 调整为 `57%`，当前桌面约上移 23px。预览与正式构建通过，日期与 READ 清晰可见，见[上移后的截图](evidence/supplement-ui-20261007/waves-position.png)。

## 几何图形中心轴

作者进一步明确右下图形是立体物，应绕其中心轴旋转。以原 PNG 的上下尖点作为固定轴端点，根据原图控制点确定环绕该轴的面片。将原 PNG 直接作为面片纹理投影，不新增或重画 SVG 棱线。完整动效模式每 13 秒绕轴一圈，既有 4.8 秒整体轻跳保留。

动画沿用现有星空绘制循环，每秒最多更新 30 次，画布按设备比例适配并限制分辨率；窗边、阅读层、页面隐藏和轻过渡模式不运行旋转。轻过渡及画布不可用时保留原 PNG 静图。

验证：25 项测试通过，新增检查初始控制点与原图一致、绕轴一圈时上下尖点固定、四分之一圈仍保持体积与整圈回位。预览和正式主题构建通过，各生成 145 个文件。桌面与手机完整动效模式均启用纹理画布，图形没有 CSS 平面旋转，窄屏画布完整处于视口内；切换轻过渡后隐藏画布、显示原 PNG，并停止整体轻跳。控制台无运行错误。
