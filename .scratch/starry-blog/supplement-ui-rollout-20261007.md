# 观测面板补充图形替换记录

日期：2026-10-07。状态：已实现并验证。

作者指出上一版小图形不准确，并新增 `assets/详情弹窗/详细工程文件/补充图形.png`，明确允许裁切或直接使用，要求不要自行绘制 SVG。本次接续[上一版记录](observation-ui-rollout-20261007.md)。

## 素材与界面

- 从补充原图直接裁出年份箭头、菱形、径向刻度、括号、斜线方框、CALL 与下划线、H-、READ 上方折线，共 8 个 PNG。原图、裁片和[裁切坐标](../../assets/详情弹窗/详细工程文件/supplement-crops/crops.json)一起保留，裁片像素与原图对应区域一致。
- 删除此前以 CSS 拼出的这些装饰图形，使用原图裁片。数字和其余技术字母使用作者字形包中 36 个现成透明 PNG，构建输出与源文件字节一致。
- 调整 YE 在原图箭头内的尺寸，桌面和手机均保留原图比例。READ 字样仍使用原有素材，按钮正常打开对应正文。
- 五行年份以文章发布年居中，月日按文章日期变化，读后标题变灰和右下几何旋转／轻跳行为沿用上一版。历史待整体复核状态保留。

## 验证

- 22 项测试通过，包含真实文章发布日期、闰日与年份边界，以及所有观测素材／字形的原样发布。
- 预览与正式主题构建通过，各生成 142 个文件。
- 桌面和手机实看：没有缺失图片或横向溢出，YE 位于年份箭头内，READ 可打开对应正文。检查日期 `2025-10-20`，中心年份为 `2025`、显示 `25`，月日为 `10.20`。
- 另一篇文章 `2026-07-05` 返回星空后显示 24–28、中心 26、月日 `07.05`，所有动态字形加载原 PNG。
