# 检索整体关系优化

日期：2026-10-12。作者先要求说明调整方案，随后明确授权“开始”。本轮本地实现，未发布；视觉供作者反馈。

## 改动

- 标题、搜索与筛选共用左边界。星图区独立排布，展开右侧索引时保持地图尺寸，图面整体平移居中。
- 搜索框收窄并减弱亮青色，保留原素材宽高比；筛选独立放大，完整显示当前两年与三个星等，选项继续采用原黑条、数字及细线选中。
- 背景装饰降低强度，纯蓝边缘采用 18px 窄范围渐隐。底图含网格的部分在背景层隐藏，同一原图中的网格裁片独立跟随星点容器定位；灰度、对比与滤色叠放避免裁片带来另一块圆形底色。所有原始 PNG 保持不变，未另画网格。
- 本轮直接核对当前源图片：`底图v2.png` 含圆网格，`检索原型图v2.png` 不含。此前文档对此描述相反，当前实现和设计记录已修正。
- 文章星点由 4／6／8px 调为 5／7／9px；悬停或键盘聚焦显示就近标题。44px 星点点击区与真实坐标保持独立。
- 检索背景模糊为 1.2px，遮罩 15%，READ 聚焦帧和 440／240ms 时序沿用；文章页未改。减少动态的 160／120ms 无模糊过渡沿用。
- 手机下方索引有独立 INDEX 标识，外层允许滚动；短横屏通过图面内滚动保留控件可读尺寸。

## 验证

`npm test`：83 项通过。包括原 PNG 逐字节发布检查、全量正文检索、筛选和实际星位计算。最后的纯布局微调以浏览器再次核对；双主题生产构建成功，新版在 `/`，Kira 在 `/legacy/`。

应用内浏览器核对 1440×1000、1024×768、390×844、320×568、844×390 五种视口：标题与搜索左边界一致、两组筛选无水平裁切、页面无横向溢出、收起／展开的圆图尺寸一致。桌面 1440×1000 收起 778×820、展开 1168×820，圆图均约 529px。手机 390×844 收起 358×552、展开 358×780。短横屏面板高 342px，可滚到完整圆图。

实际交互核对：2025 筛选为 5 篇；再加 1.0 星等为无结果；清除后保持展开；SLD-0006 命中《慢》，阅读返回保留条件；空查询时 Escape 退出，非空搜索框第一次 Escape 由浏览器清空输入；重新进入为空条件且收起。内部点击不关闭，点击外侧关闭。键盘聚焦星点的长标题完整显示在附近。浏览器未记录警告或错误。

几何与交互记录见 [browser-summary.json](browser-summary.json)。截图保留本地并按仓库约定忽略：`desktop-before.jpg`、`desktop-closed.jpg`、`desktop-open.jpg`、`mobile-closed.jpg`、`mobile-open.jpg`、`landscape-open.jpg`、`landscape-scrolled.jpg`。
