# 检索小图标交互反馈

2026-10-12，按作者截图要求，为搜索、开合箭头与关闭图标添加轻量悬停反馈。

- 搜索：使用同一 `frame-v3.png` 的原坐标裁片，放大 8% 并提亮。静止时显示完整原 PNG；返回动效结束后移除局部裁片，避免裁切边缘影响静止图稿。
- 箭头：反馈外层沿指向移动 2px、放大 9%；内部原 PNG 的收起 90°／展开 0° 和 360ms 开合曲线独立保留。
- 关闭：倾转 10°、放大 10% 并提亮。提高按钮层级，让手机索引透明区域不再挡住按钮。
- 三者以 220ms 进入／返回，青色投影轻微强调按钮；按下轻微收缩，点击区域固定。键盘聚焦沿用相同反馈；精细指针设备才启用悬停，减少动态效果时取消新增位移、缩放和旋转，保留提亮。
- 没有新画图标、修改 PNG 或改写搜索逻辑。
