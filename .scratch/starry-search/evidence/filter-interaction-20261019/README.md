# 筛选暗星不可选

日期：2026-10-19。本地实现，4175 预览已更新，未线上发布。

## 问题与修改

原实现只用 `is-muted` 降低未匹配星点的亮度，按钮仍可悬停、聚焦并进入阅读。以年份筛选 2025 为例，「随笔2」仍然能够显示旁注并打开正文。

现在按同一筛选结果设置原生按钮 `disabled`，保留原暗星亮度；高亮与阅读入口也检查匹配状态，避免旧事件进入已被筛除的文章。条件变化后清除已失效的高亮、旁注与星图选择标记，阅读准备等待结束时复核条件。取消或清除条件重新启用匹配星点。年份、星等与关键词共用这条规则。

## 验证

```sh
node .scratch/starry-search/evidence/filter-interaction-20261019/check.mjs
```

该脚本使用实际鼠标悬停和坐标点击，修复前记录为 `muted: true, disabled: false, highlighted: true, readerOpen: true`，禁止打开正文的断言失败；修复后为 `muted: true, disabled: true, highlighted: false, readerOpen: false`。

后续检查通过：

- 2025 年筛选禁用 5 颗未匹配星点；Tab 只到达 5 颗匹配星点。
- 再次点年份、清除全部条件及清除关键词后，星点全部恢复可选。
- 悬浮文章在筛选后失效，旁注立即收起；即使分发旧高亮／点击事件，也不会选中或打开正文。
- 年份与星等交集为空、关键词零命中时，全部星点禁用。
- 搜索 `SLD-0007` 只启用对应星点，可以阅读；关闭正文后保留关键词和禁用状态。
- 390 × 844 手机触屏模拟：实际点按暗星不会打开正文；取消筛选后，同一颗星可以点按阅读。
- 暗星按钮没有叠加全站通用的禁用透明度；无页面脚本错误。
