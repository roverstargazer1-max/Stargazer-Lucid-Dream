# 检索页反馈修订验证（2026-10-11）

作者提出七项视觉与交互修正。本次沿用上传 PNG，并核对原设计 U03／U04 及 §3.3，纠正仅隐藏列表、没有收起右侧面板的初版实现。最新范围见 [设计记录](../../spec.md)。

- 方位小星图从页面及交互中移除，拖动、滚轮与方向键探索均不会显示。
- 常驻入口发布为 `images/search/entry-blue-purple.png`，使用 `assets/蓝紫星盘.png` 原始字节；新资源名明确区分此前入口，白色外围仅在页面裁切。
- 默认裁出左侧星图区，桌面展开索引时实际扩大弹窗宽度；手机展开时增加高度并滚动显示下方索引。背景主页可见，桌面最大占视口 88% 宽／82% 高，手机左右留 16 像素、上下至少 32 像素。
- 进入／退出有 320／240 毫秒的淡入淡出、轻微缩放和位移，展开面板为 360 毫秒，索引自身淡入；关闭过程中继续阻止背景操作。减少动态效果设置下立即切换。
- 展开箭头从原始方向顺时针旋转 90°，收起恢复；没有 180° 旋转。
- 筛选选项裁切原 PNG 的整块黑底、边线和数字，现有文章只显示 2026／2025，裁去 2024。其他实际年份使用原素材的空白黑条及已有数字字形。
