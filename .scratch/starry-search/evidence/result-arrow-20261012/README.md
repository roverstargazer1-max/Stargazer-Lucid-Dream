# 索引原图箭头与悬停动效

2026-10-12，按作者的新截图及提供的 `assets/补充素材/补充/箭头.png` 替换索引选中菱形。本地实现与预览已更新，未线上发布。

原 40×30px PNG 在双主题构建中发布为星空版的 `images/search/result-arrow.png`，逐字节核对原图一致；CSS 以 18×13.5px 显示，无重新绘制。沿用原标记的装饰语义与星图、列表双向高亮，标题与日期位置保持。

## 动效

- 标记容器在 260ms 内从轻微缩小、左移状态滑入，180ms 显影。
- 原图独立执行 420ms 单次轻弹：向前 3px、倾转 −6°、放大至 1.14，再轻微回摆、停稳。结束后回到静态样式。
- 移开后容器平滑缩回淡出；点击时原图微缩并提亮。键盘聚焦采用相同反馈，减少动态效果设置下取消位移、倾转与轻弹。
- 列表与展开面板左侧裁切范围同步扩到 28px，箭头在正常位置与文字至少相隔 6px。

## 验证

Chromium 核对桌面 1440×1000、手机 390×844、窄屏 320×568、横屏 844×390，以及桌面减少动态效果。后三种移动视口启用触摸模拟。

实际动画在 0、147、286、420ms 采样呈现四种不同变换，减少动态效果下均为 `none`。悬停标记可见，移开后透明度回到 0，键盘聚焦可见，箭头及文字无重叠、无边缘裁切。手机点按和桌面点击都可阅读并返回，页面无脚本异常。详细采样见 [browser-summary.json](browser-summary.json)，`desktop-search.png` 与各设置的 `*-index.png` 截图保留本地。

最终使用默认完整动效补查桌面、手机与减少动态效果：轻弹完成后箭头没有持续动画或残留变换，移开能收回，再次悬停重新触发，星图聚焦仍同步显示对应箭头，退出检索正常。见 [settled-summary.json](settled-summary.json)。预览与生产输出的箭头均与原 PNG 字节一致。
