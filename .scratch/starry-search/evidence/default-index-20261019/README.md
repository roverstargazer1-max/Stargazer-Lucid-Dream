# 星图默认连续展开索引

日期：2026-10-19。本地预览已更新，未线上发布。

作者要求先打开左侧星图，再自动平滑展开右侧索引，并进一步反馈首尾衔接仍有停顿感。当前在首次入场时间进度约 40% 时就启动索引，此时左侧视觉上已展开约 92%，其余运动继续执行。首次索引揭示缩短为 420ms、取消 60ms 额外等待，列表入场间隔减半且无首行等待；与左侧末段重叠。首次光圈提前预留展开后的宽度，避免在最终解除裁切时突然露出右边缘。手动开合、阅读返回、途中取消和每次重新打开的默认展开均沿用。

## 验证

```sh
node .scratch/starry-search/evidence/default-index-20261019/check.mjs
```

桌面 1440 × 900、手机 390 × 844、桌面减少动态效果与桌面轻过渡均通过：

- 逐帧采样确认先出现收起的左侧星图，右侧在左侧仍运动时展开。正常桌面、手机与减少动态效果下重叠约 533ms；轻过渡也在入场结束前开始展开。正常入场在停稳前已揭示索引，光圈覆盖新增面板，无最后补出的边缘。
- 桌面宽度由 827.66px 平滑变为 1101.81px，普通／轻过渡捕捉到中间宽度；圆图继续原有入场转动与缩放，布局宽度不因索引开合变化。手机沿原下方排布展开，面板宽度保持 358px。
- 展开后索引可交互、列表有文章；手动收起后不会自动反弹，再次展开正常。
- 桌面手动收起后阅读并返回，仍保持收起；从星盘重新打开则默认展开。
- 桌面打开途中按 Escape 退出，不会延迟展开；再次打开正常。四组无页面脚本错误。

`browser-summary.json` 保存状态和尺寸摘要，截图仅保留本地。最新旁注回归脚本已适配新的默认开合状态；旧日期证据保留历史过程。使用 Node 22.19.0／npm 10.9.3 验证 `npm test`（93 项通过）及 `npm run build`（双主题构建通过）。
