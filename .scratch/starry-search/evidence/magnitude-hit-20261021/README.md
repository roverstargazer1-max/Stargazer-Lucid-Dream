# 星等按钮点击遮挡修复

2026-10-21，作者反馈检索页的 2.5、4.0 星等无法点击。

## 复现与原因

真实鼠标操作复现：完整动效下 1.0 可选，2.5、4.0 点击超时；按钮中心的 `elementFromPoint` 命中 `.search-map canvas`。切换到轻过渡后，三个选项均可正常选择，因此筛选逻辑与事件绑定正常。修复前结果见 [reproduction-summary.json](reproduction-summary.json)。

完整动效为筛选区与星图区分别设置变换，形成两个同级层叠上下文。星图区在后，其矩形透明画布左上角盖住了后两个星等按钮；筛选选项自身的层级无法越过父级上下文。

本轮只为 `.search-filters` 设置 `z-index: 1`，将筛选区整体置于透明画布上方。按钮原坐标、原图、动效与筛选逻辑保持原样，圆形星图区的文章星点仍可操作。
