## 素材与布局

原型画布 2209 × 1631；蓝色主面板从 (225,77) 至 (2209,1421)。桌面主面板保持 1984:1344 的原始比例。原搜索栏有透明留白，在页面内裁切显示可见框体；标题、箭头、NAME／OBS／ID 与退出按钮按原型位置叠放。主圆图中心为原画布 (1050,838)、半径约 449，真实星位按天顶居中、地平线在圆周投影，不重画现有网格。

九张检索页拆分素材与入口原 PNG 均原样发布，自动检查比较文件字节。没有新增 SVG 替代素材。新入口 PNG 的外围白底由 CSS 沿原图外轮廓裁切，保留外伸指针，不改 PNG 内容或色彩；轮廓复算脚本为 [entry-outline.py](entry-outline.py)。筛选标签与底线裁切自原筛选条，动态年份／星等数字复用已提供的观测数字 PNG。

手机竖屏复用同一底图与控件，圆图位于上方、索引位于下方，结果区独立滚动；横屏沿用左图右列。实体触屏尚未验证。

## 功能与验证

[check.mjs](check.mjs) 在 1440 × 1000、390 × 844、844 × 390 的浏览器视口验证：

- 常驻星盘入口及小星图入口；新进入默认收起，手动展开列出 10 篇真实文章。
- 搜索自动展开，清空保持展开，手动收起后改变非空条件重新展开。
- 实际年份、星等与关键词组合；无结果及清除恢复；大小写不敏感的永久星表号与完整正文末段命中；输入法完成前不变更列表。
- 筛选前后所有星位一致，索引只显示匹配文章。
- 标题单击直接阅读正确文章、实际文章地址同步；关闭、浏览器前进／返回恢复本次检索。
- 读后保留列表滚动位置；退出再进入清空条件；退出按钮与 Escape 可用。
- 正文检索数据只在首次打开请求一次。模拟检索数据 503 时提供明确不可用信息，清除后仍可浏览全量文章；文章 503 时保留检索页和原地址，并显示重试信息。
- 三种视口均无未捕获页面错误。结果见 [browser-summary.json](browser-summary.json)。
- 时间模式详细图逐篇核对真实时间布局投影；完整动效模式下打开检索后背景画布保持不变，关闭后恢复探索。

`tests/search.test.mjs` 覆盖筛选交集、检索范围、排序、坐标不变、真实视野逆投影、原素材字节一致及全部正文数据与实际渲染文章一致。最终完整自动检查 **83／83 通过**，统一双主题生产构建通过，新版在 `/`、Kira 在 `/legacy/`。最终检查覆盖作者选定的新蓝紫星盘；原图与预览、生产入口文件的 SHA-256 均为 `5EA31DB8469ADCD2D1F3D9A7AC581A09EC856595002CF955B72EE37A7AF56086`。
