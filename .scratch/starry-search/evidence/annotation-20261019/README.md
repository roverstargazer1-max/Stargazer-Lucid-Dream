# 星图旁注与索引跟随

日期：2026-10-19。作者选择「星图旁注」，要求用斜线连接文章星，并修复悬停星点后右侧对应索引行仍藏在可视区外的问题。本地实现，未线上发布。

## 实现

- 文章提示去掉底板、完整外框与投影，保留原 LXGW Marker Gothic；左对齐标题，下方分列日期、星表号和博客星等，配细横线。
- 引线自定位环外侧 17px 处斜向生长，连接横线偏心位置；贴近左边缘时改变斜向，顶部空间不足时换到星点下方。用实际文字尺寸和星位定位，窗口或文字重排后同步更新。
- 根因是原 `highlight()` 只切换星点、索引行的高亮和标题，没有检查索引可视区或更新滚动位置。
- 文章星悬停／键盘聚焦只调整展开的 `#search-results`，露出对应整行，并保留约 8px 余量。原本可见、索引收起或该文章被筛除时保持位置。
- 只在星点事件上触发跟随，避免滚动中的索引行进入鼠标下方后触发连续滚动。新星点中止上一段尚未结束的滚动；轻过渡与减少动态效果使用即时定位。

## 复现与验证

最小回归命令：

```sh
node .scratch/starry-search/evidence/annotation-20261019/check.mjs
```

在 1440 × 700、轻过渡下，打开星图并展开索引，列表置顶，实际鼠标悬停「随笔1」。修复前对应行已高亮，滚动值仍为 0，行范围 589.06–658.84px 在列表下边界 553.25px 之外，整行可见断言失败。修复后滚动值为 113，行范围变为 476.06–545.84px，整行可见断言通过。

完整浏览器验证：

```sh
node .scratch/starry-search/evidence/annotation-20261019/validate.mjs
```

- 七组条件：1440 × 900、1440 × 700、390 × 844、320 × 568、844 × 390、桌面减少动态效果、短桌面轻过渡。
- 每组逐一检查现有 10 篇文章，共 70 组标题布局：无底板、无投影、信息完整、标题不超出星图、引线保持倾斜并对准定位环外缘与横线。
- 每组验证隐藏行完整露出、可见行原位、快速切换后以最后目标为准、收起状态与被筛除文章不滚动、外层图面／页面／焦点保持原位；无页面脚本错误。
- 桌面从星点直接阅读并关闭正文后，恢复展开索引和对应旁注。
- 使用 Node 22.19.0／npm 10.9.3 完成 `npm test`，93 项通过；`npm run build` 双主题生产构建通过。4175 本地预览已更新。

`browser-summary.json` 保存布局与交互摘要。截图和逐次复现输出只保留本地，遵循[测试产物约定](../../../starry-blog/evidence/README.md)。脚本默认使用 Codex 本地浏览器运行时，可通过 `PLAYWRIGHT_PATH`、`CHROMIUM_PATH`、`PREVIEW_URL` 指定其他环境。
