# 星盘指针跟随视角

日期：2026-10-12。本地实现，未线上发布。

## 实现

作者要求蓝紫星盘的指针真实指向用户视角的平面方向。以实际相机 yaw 为水平投影，上方 +Z、右方 +X，与详细星图相同；正上方保留 yaw，俯仰、镜头缩放及相机平移不额外改变方位。

`astrolabe.js` 随既有搜索入口的共享帧更新同步指针；隐藏时不更新，水平角度未变时不写样式，没有独立动画循环或额外缓动。拖动、键盘和自动转向读取同一相机状态，模式和阅读返回无须维护第二份方向。

CSS 从原 `assets/蓝紫星盘.png` 分别裁切固定盘面、指针及轴心。轴心坐标为 `(615.5,644.5)`，原针尖 `(919.5,103.5)`，原方向为 `0.5119505558445387rad`；实际旋转减去此原方向。盘面中的固定针区域裁为空洞，叠放 imagegen 修补图，避免资源尚未加载时露出双针。修补图只在旧针占位使用，其余盘面继续显示原 PNG；素材、轮廓及完整提示词见 [素材记录](../../../../assets/检索页/entry-heading/README.md)。星盘大小、位置、点击检索与之前修好的检索开合箭头沿用。

## 验证

- `node --test tests/*.test.*`：86 项通过。新增测试将实际更新后的指向与投影模块的水平视线及详细星图比较，覆盖四方位、俯仰、天顶、缩放、静止去重、小转向及跨圈；素材发布仍逐字节核对。
- 双主题预览与生产构建通过，新版 `/`、Kira `/legacy/`，没有更改原文章或身份登记。
- 应用内浏览器初始 yaw 为 `1.0471975511965976rad`；24 次向右键后为 `3.2071975511965967rad`，正好增加 `24 × 0.09rad`，跨过 π 后继续同步。
- 6 次抬头与一次滚轮缩放保持该 yaw；实际拖动后变为 `2.8259306658973475rad`。盘面计算后的 transform 始终为 `none`，指针使用原轴心旋转。
- 切换时间模式，自动转向中采样为 `2.746255429495951rad`，结束为 `−0.3rad`，确认为实时跟随。验证中原预览服务停止，重新启动后文章加载恢复；未修改文章加载逻辑。
- 最终浏览器检索开关及针／盘面加载核对见本地截图与 `browser-summary.json`。完整截图保留本地、不提交。

仅本机浏览器验证；未在线上或实体触屏设备验收。
