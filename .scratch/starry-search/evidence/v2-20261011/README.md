- 原型、底图、搜索栏替换为 v2，发布资源名分别为 `grid-v2.png`、`base-v2.png`、`frame-v2.png`，不再生成第一版底图及搜索栏。入口仍为作者选定的 `assets/蓝紫星盘.png`。自动检查逐字节核对全部 11 个发布 PNG，没有替代 SVG。
- v2 蓝色面板范围为原画布 `(259,104)–(2177,1388)`。按该范围裁切，左侧和底部删去的边框没有补回。新版底图本身不含完整圆网格，圆图仅从 v2 原型裁出，其他装饰沿用 v2 底图。
- 新进入只展示左侧星图、STAR CHART、搜索栏、筛选和右上箭头，隐藏 INDEX 及退出按钮。收起箭头朝左下，展开顺时针再转 90°；展开后才出现索引、INDEX 和退出按钮。
- 选中筛选用 2px 细线和轻微提亮，不覆盖半透明方块，原 PNG 黑底、青色边线和数字保留。年份依实际文章生成，当前为 2026／2025。
- 检索与 READ 阅读窗口共用聚焦动画帧、时长和背景规则。常规进入 440ms，从 2px 模糊淡入至清晰；退出 240ms，淡出至 1.5px 模糊。背景同步渐变至 15% 遮罩、2.4px 模糊。减少动态效果时为无模糊的 160／120ms 淡入淡出。展开面板仍为 360ms。
- 外侧点击、Escape 及展开时的退出按钮均可关闭。打开到一半也能退出，关闭过程中保持原生弹窗；内侧点击及从内侧拖到外侧不会误关。阅读后返回保留筛选、索引状态、滚动及视角。
- 四周保留主页。桌面 1440 × 1000：收起约 911 × 820，展开约 1225 × 820；手机 390 × 844：收起约 358 × 500，展开 358 × 780，左右各 16px、上下至少 32px。
