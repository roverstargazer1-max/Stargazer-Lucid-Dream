# 检索页 v3 原稿对齐

日期：2026-10-12。本地实现，未线上发布。作者要求严格采用新增 v3，仅修正 UI，保留交互与动画，禁止自行重画 SVG。

## 改动与来源

- 参考 `assets/检索页/检索页v3.png`，有效面板为 `(259,104)–(2176,1388)`，尺寸 1917 × 1284。打开的 `博客-恢复的.psd` 对应面板是 `(2944,165)–(4861,1449)`。
- 通过 Photoshop 原生脚本接口在临时副本中导出。完整工程面板与原稿有效区域逐像素一致；只导出检索组会漏掉父级合成作用，故保留完整层级。原工程没有保存或改写。
- `assets/检索页/v3/` 保存底图及八种透明控件。导出 Alpha 与原稿完整合成色一起解析，以保留 Photoshop 调色／混合后的颜色，避免透明导出再叠放时的偏色。八种控件的原生可见区域与原底图重组后，RGB 最大与平均差均为 0；整组重组与原稿有 99.947% 的像素完全一致，RGB 每通道平均差为 0.00171／255，仅保留透明边缘合成差异，见 [重组结果](recomposition-summary.json)；见 [素材核对](asset-summary.json)及 [原稿核对](comparison-summary.json)。所有形状和纹理都来自原工程／v3 像素，没有生成图、SVG 或重画网格。
- 桌面按统一原稿单位定位：标题 `(598,16)`，搜索 `(166,110)`，筛选 `(179,240)`，圆图 `(342,285)`、直径 897，INDEX `(1583,46)`，NAME `(1428,185)`，OBS／ID `(1859,169)`，退出图标 `(1858,11)`。取消额外亮度、饱和度、渐隐和灰度滤色，圆网格直接采用底图已有线条。
- 收起左区为 1440 单位，展开右区增加 477 单位；圆图保持尺寸。实际年份仍为 2026／2025，2024 示例不作为选项。手机保留上下索引排布，短横屏保留内部滚动。
- 箭头以 v3 为基准，仍顺时针旋转 90°，沿用 360ms 曲线。READ 的 440／240ms 聚焦、减少动态的 160／120ms、背景 15% 遮罩与 1.2px 模糊、星点／视野／标题反馈、查询和阅读返回逻辑保持。

## 验证

- 现有自动检查：83 项通过；v3 发布文件逐字节等于源素材，检索页没有新增 SVG。
- 双主题预览与生产构建通过，新版在 `/`、Kira 在 `/legacy/`。
- [浏览器检查](check.mjs)覆盖 1440×1000、1024×768、390×844、320×568、844×390 五种视口。收起／展开圆图尺寸一致，网格与交互图层中心／直径误差均小于 0.03 CSS 像素；没有水平溢出和页面异常。几何结果见 [browser-summary.json](browser-summary.json)。
- 各视口都验证了：2025 返回 5 篇、叠加 1.0 返回 0 篇、清除恢复 10 篇且保持展开、SLD-0006 命中《慢》、直接阅读后返回保留条件、Escape 退出、新会话清空并收起、点击外侧退出。
- [完整动效检查](check-motion.mjs)在 `no-preference` 浏览器中验证打开／关闭、360ms 箭头与面板展开曲线、两态圆图稳定；结果见 [motion-summary.json](motion-summary.json)。原程序以规范化 1000ms 时间线由共享帧时钟驱动实际 440／240ms 时序，计时包含自动点击开销。
- 当前应用内预览已打开检索并展开索引供查看；应用内浏览器的系统减少动态设置仍正常生效。

原始导出及颜色提取流程见 [export-v3.js](export-v3.js)、[extract-composed-colors.py](extract-composed-colors.py)。导出脚本需要 Photoshop 中打开上述工程；运行后先验证完整面板与原稿一致，再提取合成色。构建只读取已经保存的 PNG，不依赖 Photoshop、Python 或临时依赖。

截图与中间素材按仓库约定保留本地、不提交：`desktop-before.png`、各视口 `*-closed.png`／`*-open.png`、`composite-v3.png` 等。真实触屏与线上部署未验证。

## 手机筛选比例反馈修订

2026-10-12，作者反馈手机筛选框明显过大。本轮只改手机竖屏样式：筛选取消独立 290px 放大，按 v3 的筛选／标题宽度比 311／368 随标题缩放。390px 手机宽度约 145.2px（此前 290px），320px 窄屏约 116.8px（此前 240px）。原 PNG、桌面与短横屏比例、交互和动画沿用。

圆图及底图同步上移，筛选底部到圆图保留 16px 间距，面板高度与下方索引随之收紧；真实圆网格和星位尺寸不变。五种视口的原有浏览器检查重跑通过，包括两态地图尺寸、网格对齐、无水平溢出、两组筛选、清除与阅读返回。双主题预览与生产构建通过。更新后的截图为 `mobile-open.png`，之前的手机截图保留为 `mobile-filter-before.png`；本地预览已刷新，未线上发布。
