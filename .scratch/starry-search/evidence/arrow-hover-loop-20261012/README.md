# 索引箭头常驻轻跳

2026-10-12，作者要求鼠标悬停期间持续小跳，节奏柔和，让当前选择始终可感知。本轮仅修改 `search.css` 的箭头动效，沿用原黄绿色 PNG、大小、位置和滑入淡出。

循环时长为 `--dur-panel × 3.5`，当前为 1470ms。首尾均为原姿势，中段上移 2px、向前 1px、倾转 −1.2°、放大 3.5%；两段沿用 `--ease-drift` 缓慢起落，循环接缝没有姿势跳变。悬停、键盘聚焦和星图高亮均持续循环；移开后原容器缩回淡出，点击暂停循环并微缩提亮。系统减少动态效果下保持静态。

Chromium 检查桌面 1440×1000、手机 390×844、窄屏 320×568、横屏 844×390 及桌面减少动态效果。持续悬停超过两个周期，各正常设置均取得 5 个不同姿势，动画次数为 `infinite`；减少动态效果只有同一姿势。量测确认位移、放大不超过设计范围，箭头没有裁切或遮挡文字，点击热区保持固定。移开后动画取消、标记透明度归零；键盘聚焦、手机点按及阅读返回均正常，无页面脚本异常。见 [browser-summary.json](browser-summary.json)，各设置的索引截图保留本地。

双主题预览与生产构建通过，构建日志无 `ERROR`。此记录覆盖 [原单次轻弹](../result-arrow-20261012/README.md) 的停稳要求；未线上发布。
