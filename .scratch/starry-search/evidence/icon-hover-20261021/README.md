# 放大镜悬停只影响图标

2026-10-21，作者要求检索文章按钮只对放大镜本身做悬停反馈，搜索栏的蓝色纹理保持静止。

## 原因与修改

旧实现把 `frame-v3.png` 的 `(1088,30)–(1194,92)` 矩形裁片整体放大、提亮，该范围同时包含蓝色背景。实际浏览器复现中，图标右侧 319 个蓝底采样点有 214 个变化，最大 RGB 差为 76 色阶。

本轮将原 PNG 的白色笔画与蓝底拆开：`magnifier-v3.png` 的非透明范围为 `(1099,37)–(1148,83)`，仅保留与原白色笔画相连的 462 个像素；`frame-background-v3.png` 保持其余蓝色纹理原样，只用相邻原图蓝色像素补齐笔画下方。通过透明度分解保留原合成色，两张缓存在原生尺寸上重组后，与原 PNG 的 RGB 最大差异为 1 色阶。没有重画图标、SVG 替代或生成图像，原 `frame-v3.png` 保留不变。

静止时直接显示完整原 PNG，保证既有静止图稿。悬停、键盘聚焦或按下时换用静止蓝底与透明图标；只有图标参与原有放大、提亮、青色投影与按下收缩。离开时等图标复位后切回原 PNG，避免提前叠加原图标；减少动态效果时取消缩放。按钮热区、搜索、筛选与阅读逻辑沿用。

## 复测

`check.mjs` 使用真实 4175 预览，在桌面、手机、窄屏、横屏及减少动态效果下比较悬停／按下／键盘聚焦前后的蓝底像素，检查热区、离开复位、原图静止效果，并实际检索 `SLD-0006`、阅读《慢》。结果保存于 [browser-summary.json](browser-summary.json)。手机为触屏模拟。

五组检查全部通过，所有反馈状态的蓝底采样均为 0 变化，热区保持固定，静止均恢复原 PNG，检索与阅读正常，无页面异常。103 项自动检查及双主题预览、生产构建通过。

`split-art.mjs` 是缓存生成脚本，需要 `pngjs`，可通过 `NODE_PATH` 指向本机依赖目录。`check.mjs` 的浏览器与依赖路径按本机运行环境配置。日常构建直接发布已保存 PNG，不依赖这些工具。源图 SHA-256、像素数和原生重组差异见 [asset-summary.json](asset-summary.json)。截图按仓库约定保留本地。
