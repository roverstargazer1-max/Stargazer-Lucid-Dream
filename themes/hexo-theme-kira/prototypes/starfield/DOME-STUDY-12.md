# V12：半球穹顶、方位星图与云层遮光

日期：2026-09-10。原型分支：`codex/prototype-starfield`。

作者要求天空能在整个半球上自由转向，文章布局在穹顶上；增加拖动出现、静止消失的小星图，并处理云与星光重叠时的突兀感。当前继续沿用 V11 动画厚涂和窗边入口，不改变主设计 R1–R6 的待整体复核状态。

## 体验

<http://127.0.0.1:4173/pages/starfield-prototype/?scene=painted&variant=C&v=12>

- 进入窗外后按住拖动：水平可连续转圈，仰角从地平线 0° 到天顶 90°。方向键也可转向。
- 滚轮或双指张合靠近／拉远。点星先推进与聚焦，到位后再点一次进入正文。
- 转向、靠近时显示小星图，停止约 2.8 秒后开始 0.7 秒淡出。也可点击“◎ 星图”重新显示。
- 图中心为天顶，外圆为地平线，点代表文章，亮框是当前视野，金圈标明观察方向。点击图内位置可转向该处。
- 阅读返回保留位置、朝向、缩放和所选文章；房子按钮回到窗边。

## 实现边界

`dome.js` 提供共享半球几何、正反投影、球面交点、布局和目标镜头。16 篇 mock 文章改为固定半径 6000 的上半球坐标，覆盖四周与天顶。时间模式为按日期顺序逐渐升高的球面螺旋。试加文章只在上半球找新位置，不移动旧星；孤立配置继续生效。

`dome-renderer.js` 使用原生 WebGL，将每个屏幕像素的观察射线与球面求交，再采样已有厚涂素材。云、月亮、装饰星、文章星使用相同空间和镜头，不再通过横向图片平移模仿转向。低空保留厚涂云景，天顶提前融合为统一蓝色，避免纹理在极点汇聚成条纹。

靠近时采用有限镜头前移与视野收窄，镜头始终在球内，避免穿出星壳或将地平线以下当作文章空间。镜头目标选择最短的方位旋转，精确到天顶也没有无效坐标。

云层使用同一投影再覆盖一次云色，依据素材中相对底色的亮度差估计云的浓度，减弱其后的星核、光晕、月亮和路径。文章亮度不会在进入云中时骤然切断；命中区域保留。另收小原有大光晕，抑制素材里被球面投影拉长的零星亮点。

这仍是本地 mock 原型：云是球面贴图与光学遮罩，不是体积云或天气模拟；未生成新素材，未接真实文章、未部署。当前天空渲染需要浏览器支持 WebGL。真实触屏手感、长期性能及最终美术仍待体验反馈。

## 验证

- `node .scratch/starry-blog/dome-check.mjs`：80 组射线与正反投影、一整圈接缝检查通过；两个布局均在上半球，所有目标从各方位和天顶都可到达；新增星保持半径及已有位置。
- 本机无头 Microsoft Edge 实际渲染为 WebGL，桌面 1440×900，手机视口 390×844；抬头可到 90°，转到另一面能发现文章。手机没有横向溢出。
- 实际云层覆盖层的最大 alpha 为 199/255；白色测试像素经过厚云后为 `[68,103,182]`，证明星光经过云色遮挡。水平旋转 360° 前后平均通道误差为 0.0000875/255。
- 拖动后小星图出现；静止后 opacity 为 0、inert 为 true。图内点击实测转向东南、仰角 19°。
- 桌面 night 阅读前后镜头均为 `(-189,450,756)`、方向 `(-0.24,0.45)`；手机雨后文章 rain 切换时间模式仍保持选中并能阅读，阅读层横向溢出为 0。
- 浏览器检查未记录页面脚本错误；新增及修改 JavaScript 的语法检查通过。
