# 第三轮：字标、阅读排版与按需标题

日期：2026-09-09。原型分支：`codex/prototype-starfield`。

[打开第三轮](http://127.0.0.1:4173/pages/starfield-prototype/?variant=C&roof=anime&art=ink&labels=reveal)。底部展开“画面试验 03”，可切换“标题 · 按需 / 常显”，并继续使用前两轮的配色、微动和样本对照。

## 字标与界面

- 参照作者提供的衬线字标方向，将英文站名分为两行，以衬线和斜体形成字形节奏；细线弧饰与少量星点使用内联 SVG，中文站名作为小落款。
- 字形使用本机 Baskerville / Times 等衬线字体及后备字体，没有打包或分发系统字体。当前是字标编排原型；跨设备字形可能不同，正式定稿需确定可分发字体或固定矢量字形。
- 减少导航装饰，试验控件默认折叠，天空里移除常驻日期与文章序号，日期仍在文章预览和正文保留。
- C 预览层收窄，重新安排标题、引言和操作间距；阅读层降低纸面亮度，采用灰绿墨色、宋体正文、16px 正文字号与较宽行距，调整页边距与标题比例。
- 删除阅读结尾的装饰旁白，保留读完检测、关联理由和继续探索入口。

## 标题的新实验规则

作者提出默认不显示文章标题是否更好。本轮以“按需显露”作为可回退的实验默认，不据此将主设计文档原有的靠近显题规则永久替换。

- 闲置时只显示文章星光，不显示标题。
- 有悬停能力的设备：鼠标停到文章星后显露标题；移开后未选中标题淡出。
- 键盘：聚焦文章星时显示标题，完整文章名称始终保留在无障碍名称中。
- 选中后：标题持续保留。手机首次点选同时显题、显示引言并推进，到位后再次点选才打开正文。
- 阅读返回：恢复同一颗已选星，标题继续保留。
- “标题 · 常显”恢复近处文章标题的既有行为；URL 使用 `labels=all`。切换不重置探索或阅读状态。

按需显示优先让天空形成完整画面，常显更适合快速找文。最终取舍等待作者探索反馈；不以隐藏文字代替文章星可发现性的实际评估。

## 已检查与边界

浏览器检查首屏 3 颗可见文章星标题 opacity 均为 0；键盘聚焦 answer 后只有对应标题变为 1；选中及阅读返回的 night 标题保持 1，镜头仍为 (-360, 38, 1020)。窄屏常显对照恢复 3 个标题，按需模式首次点选后出现预览且正文未打开。桌面和窄屏字标、预览、正文均已截图检查，窄屏展开控件宽 290px，小于当前 342px CSS 视口；浏览器无脚本错误。

本轮没有重新生成屋顶或星空素材，也没有改动前两轮星体微动参数。没有引入字体网络请求、真实内容或发布构建；正式字体一致性、真机触屏手感及整体审美仍待复核。主设计 R1–R6 保持待整体复核。
