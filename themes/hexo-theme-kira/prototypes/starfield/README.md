# 星空交互原型

本地、可丢弃的 UI 实验。8 篇虚构文章，3 种结构方案，共用同一套空间坐标与交互。用于判断视觉、镜头推进及阅读衔接；不是正式主题实现。

## 启动

仓库根目录执行（无须安装额外依赖）：

```powershell
node themes/hexo-theme-kira/prototypes/starfield/server.mjs
```

也可使用 `npm run prototype:stars`。如果系统盘没有空间写 npm 日志，使用上面的直接启动命令。

打开 <http://127.0.0.1:4173/pages/starfield-prototype/?variant=C>。V2 默认以作者偏好的 C 继续迭代。

## 比较方案

| 参数 | 方案 | 结构差异 |
| --- | --- | --- |
| `?variant=A` | 屋顶入梦 | 屋顶和大片天空；右侧浮动引言；居中深色阅读层 |
| `?variant=B` | 观测手记 | 左侧固定观测栏承接选中文章；右侧阅读层保留观察空间 |
| `?variant=C` | 漂浮书页 | 摄影质感星空与屋顶；底部横向文章手记；浅纸色宽阅读层 |

底部原型工具条或键盘左右方向键切换方案。输入框或模态阅读中不拦截方向键。右下“状态”显示镜头坐标、阶段、当前文章、已读集合与停靠历史。方案会写入 URL；文章状态只在内存里。

按作者本次明确要求，V2 默认播放约 1.05 秒的快速推进镜头，先快速前行，再减速停靠。工具条可切换到 220ms 的“轻过渡”；不修改系统设置。正式版本的动态效果策略仍需结合最终体验确定。

## 体验顺序

1. 点击近处星星：第一次选中并靠近；约 1.05 秒后再次点同一颗星进入正文，也可点击“进入阅读”。移动中的重复点击不会打开正文。
2. 阅读到正文结束，出现与其他文章的关联理由。“留白也是一种回答”用于检查短文无需滚动的情况，是否直接读完取决于可用屏幕高度。
3. 返回星空：镜头和选中项恢复。也可从文末关联进入另一颗星的附近。
4. 切到时间模式：继续聚焦同一篇文章。旧文章在近处，新文章向远处延伸；虚线只表示时间轨迹。
5. 拖动转向、滚轮向上前进/向下后退。手机单指拖动、双指张开前进/收拢后退。手动操作中断自动镜头，随后再次点星先重新靠近。
6. `↶` 返回上一个停靠点，`⌂` 回到屋顶。屋顶手记可点开；远处波纹符号可触发一颗流星。

## 实现范围与限制

- 使用原生 Canvas 的透视投影与三维镜头平移，具有远近视差。远景使用用户参考图，屋顶使用生图材质与描摹轮廓裁切，构成 2.5D 混合场景；不是完整的三维房屋或体积星场。
- 关联布局横向坐标约为 V1 的 2.9 倍、纵向为 2.55 倍、纵深为 1.75 倍；时间布局的文章纵深间隔从 480 增至 1050。数值均为原型调试参数。
- 关联布局是手填 mock 坐标，时间布局根据 mock 顺序生成。普通可见目标最多 6 颗；尚未验证真实文章数量增长后的布局算法。
- 无真实文章接入、站内后台、AI 调用、跨次持久化、正式地址迁移、归档和友链整合。可选星座名称暂未填入。
- 两项彩蛋仅验证轻反馈。手机彩蛋首次触碰即触发，不据此确认设计文档 R5 的两次触碰规则。
- 已在浏览器检查桌面和窄屏布局、阅读闭环、镜头坐标恢复、时间切换、短文已读与手动巡视；双指缩放仍需真实触屏验证，尚未做性能基准测试。
- 原型位于主题的 `prototypes/`，不在 Hexo 发布资源目录。启动器拒绝 `NODE_ENV=production`，工具条只在 localhost 显示。
- 原型分支：`codex/prototype-starfield`。作者选择 C 作为继续迭代方向；A/B 保留对照，最终美术尚待反馈，不直接合入正式站点。
