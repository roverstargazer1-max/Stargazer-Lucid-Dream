# 探索路径、星等与天空生长实验

日期：2026-09-10。原型分支：`codex/prototype-starfield`。沿用现有 16 篇 mock，验证隐藏标题之后的可发现性；未接入真实文章发布流程。

## 体验

[打开探索路径版](http://127.0.0.1:4173/pages/starfield-prototype/?variant=C&roof=anime&art=ink&labels=reveal&type=white&paths=1)。

- 默认淡虚线连接文章星，边缘箭头可以带向路径尽头的下一颗星。背景装饰星不参与。
- 选中后，导航线退暗，作者确认的内容关联用较清晰实线显示。屏幕角落有线型说明。作者理由仍在读完后显示；导航线不会产生阅读关联。
- 标题继续按需显露。已有两次点选、推进、阅读返回和布局切换继续保留。
- 展开“天空试验 05”，可关掉路径作对照，选择普通、重要或珍藏，再点击“＋ 一篇文章”。试加不会移动当前镜头；“找刚加的星”可以直接检视新增结果。
- 勾选“保持孤立”，新增星不生成导航边。“导出布局”下载包含 ID、坐标、星等、孤立标记和导航边的 JSON。

**试加内容仅在当前页内存中。刷新恢复原始天空。** 导出用于保存实验布局快照，当前没有导入器、发布监听或自动写回仓库。

## 规则

导航图由 `navigation.js` 生成，与 `mock.js` 的内容关联完全分开。初始固定位置保持不变，按带少量稳定随机权重的空间距离选近邻，优先让节点拥有一条路径，再连接可达的小组，少量补充第二条。每颗星最多三条导航边，最大世界距离 3400；过远或刻意孤立的星不会强行拉长线。

屏幕上再进行边界裁切、过长线段过滤、交叉避让和远处淡出，因此某些已有世界连线在特定视角下不显示。时间模式改用时间顺序虚线，仍跳过明确标记为孤立的文章。内容关联实线独立于路径开关。

新增文章按 ID 产生稳定伪随机序列，从仍有连接余量的已有文章附近选位置；尝试避开所有旧文章，普通新星最小间距 950，手动孤立新星最小间距 3000。不移动旧星，不删除或重接旧边；普通新星连接 1–2 个近邻，孤立星不连接。位置拥挤、找不到合适候选时明确提示未添加，不修改旧状态。

普通、重要、珍藏分别使用约 1、1.25、1.55 的光核尺度，同时适度增加散射与光度。普通星保持可发现性，不因总文章数增多而被调暗。ID 决定的个体形态和已有微动保持独立；重要程度不会增加连线配额，也不使用浏览量。

孤立星默认根据导航度数识别；示例 `window` 另有明确 `isolated: true`。附近的孤立星位于视野外、但投影仍在有限邻域内时，可以显示边缘弱提示，不伪造连线。并非所有远处孤立星都会被全局提示。

## 检查

- 一次性运行 80 次插入检查：已有节点与边不变、最小间距、最大度数 3、最大边长、孤立星无边均通过；线段裁切和交叉判断检查通过。
- 浏览器试加第 17 篇珍藏文章产生 1 条导航边，能到达并阅读；文末没有显示不存在的内容关联。第 18 篇刻意孤立文章产生 0 条边，也能到达。
- 切换时间模式后仍选中 `new-note-2`。窄屏 CSS 视口宽 342，试验面板宽 290，没有横向溢出。屋顶边界及脚本语法检查通过。

## 后续边界

这轮是空间引路机制的实验，不代表真实内容自动布局、无限规模性能或读者可发现性已最终验收。正式接入时应把首次生成的坐标和导航边保存为仓库配置，随后只做增量更新；内容关系可作为布局候选偏好，但不能与导航边混为一份数据。本轮不改变主设计 R1–R6 的待整体复核状态。
